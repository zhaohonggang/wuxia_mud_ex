### 1.1 必须修复的方向性偏差

- **缺省拒绝文案全错**：`gumu.h` 三条为「唉！去便去了……」「阁下不忠不信……」
  「你既有了名师指点……」，引擎缺省是少林味「怎么一心向佛」。UCL 四处 `apprentice`
  都没覆写，实机一律显示少林文案。
- **负神被误拒**：李莫愁要求 `shen > -70000` 拒（即只收负神），但缺省 `min_shen=0`
  会先拒所有负神玩家。必须 `no_min_shen = true` + `max_shen = -70000`；
  其余三位 LPC 无侠义门，同样要关掉缺省下界。
- **杨过门序颠倒**：LPC 是 `str → 玉女心经 → max_neili`；缺省路径把 `max_neili`
  放在技能之前，且完全没有 str 门 → 两门同时失败时文案与 LPC 相反。
- **杨过 4 招 `free:1` 被错误加了同门门**：LPC `masterd.c` 在 free>0 时跳过同门校验，
  现有 UCL 却写了 `family = "古墓派"`；同时 LPC `neili` 门槛（max_neili）完全缺失。

## 2. 门序与门型（LPC 原序，不得合并/重排）

### 2.1 `gumu.h permit_recruit`（4/4 NPC 调用）

1. `detach/古墓派` 或 `betrayer/古墓派` → `唉！去便去了，回来又是何苦由来？`
2. `betrayer/times` → `阁下不忠不信，我不敢收你为徒。`
3. 已有他派 `family_name` → `你既有了名师指点，就要勤下苦功，勿要三心二意！`

### 2.2 各师父收徒门序

| NPC | 门序（LPC 原文） |
| --- | --- |
| 李莫愁 | permit → gender=女性 → `shen > -70000` 拒 → `combat_exp < 400000` 拒 → `force < 160` 拒 → `strike < 120` 拒 |
| 林朝英 | permit → `master_name == "李莫愁"` 拒 → `int < 35` 拒 → `yunv-xinjing < 120` 拒 |
| 小龙女 | permit → `per < 26` 拒 |
| 杨过 | permit → `str < 45` 拒 → `yunv-xinjing < 120` 拒 → `max_neili < 2000` 拒 |

李莫愁/林朝英/小龙女可由缺省 `permit_first` + 现有字段精确表达（配齐逐字 deny 即可）；
杨过须新增 `gate_order = "lpc_gumu_yang"`，按 LPC 原序逐门判定。

### 2.3 `masterd.c teach_pfm` 问询链（21 条）

LPC 顺序：`同门(free:1 跳过) → 已会 → shen → gongxian → sk1..sk5 → force → dodge → neili → jingli`。
UCL 必须写 `gate_order = "lpc_masterd"` 并显式 `level_order`，否则缺省路径的
「已会在同门前、贡献在杀气前」会与 LPC 相反。
李莫愁 8 条 `shen` 全为负上界（`-75000`～`-120000`），用 `min_shen` 伪键表达
「`shen < 负数` 拒」；masterd 对负数的判断是 `shen > 负数 → 拒`，引擎 `max_shen` 才是负上界——
本批按 LPC 原文把 `min_shen` 改为 `max_shen`，并配 `max_shen_deny` 逐字文案。
杨过 4 条 `free:1` 写 `no_family_check = true`，并把 LPC `neili` 映射为 `min_max_neili`。
