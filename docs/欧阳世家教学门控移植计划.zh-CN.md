### 1.1 关键错误发现（必须修正）

`ouyangfeng.c` 三条绝招现配 `gate_order = "lpc_kunlun"`。该门序（sect_master.ex:965-1025）

## 2. LPC 逐字门序

### 2.1 `ouyang.h permit_recruit`（两 NPC 共用）

1. 玩家姓名为「欧阳锋」或「欧阳克」→ `$N大怒：他奶奶的！你起这个名字是什么意思啊？`，return 0。
2. `born_family != "欧阳世家"` → `你不是我们欧阳家的人，我怎能收你为徒？`，return 0。
3. `detach/欧阳世家` 或 `betrayer/times` → `你反复无常，我不能收你为徒！`，return 0。
4. 已有别派 → `你虽然是我们欧阳家的人，但你入了其他门派，我不能收你为徒！`，return 0。

`ouyangke.c:139-146` 在 `permit_recruit` **之前**多一条：女性且 `born_family != 欧阳世家`
→ 「这位{respect}真乃我的红颜知己，可惜家规所限，不能传你武功，你还是做我的小妾吧。」

### 2.2 `ouyangfeng.c attempt_apprentice`

### 2.4 欧阳锋物品问询

- **筝谱/古筝技法**：`music_book >= 1`，发 `/clone/book/zhengpu`，广播「$n把筝谱给了$N，道：你拿去自己好好琢磨吧」，置 `music_book=0`；`reset()` 恢复 1。无 `present` 检查（可重复领取）。
- **灵蛇杖**：`is_good()` 两支（本家弟子/外人）→ 家族 → `master_id == 自己` → `shen <= -60000` → 持有者遍历（自己持有/他人持有分别不同文案）→ 发放 + 广播。

### 2.5 欧阳克

- `recognize_apprentice`：无 `can_learn/lingshe-quan/ke` → 「干嘛？没拜师就想向本少爷学东西？」；技能非 `lingshe-quan` → 「我可没答应教你其他武功。」
- `attempt_apprentice` 成功后：广播「好... 很好！」+ recruit + 若未会神蛇则 whisper 口诀并 `special/shenshe=1`。
- `ask_shenshe`：同门 → 900 秒冷却 → 库存 `shenshe_count >= 1` → 发放 `/d/baituo/obj/shenshe`，库存 −1；`reset()` 恢复 5。
- `accept_object`：复杂「送女人」状态机（性别/年龄/出身/容貌/次数 → 银两 20+addition、shen−addition、can_learn count、传送丽春院、10-20s 后 do_back）。
