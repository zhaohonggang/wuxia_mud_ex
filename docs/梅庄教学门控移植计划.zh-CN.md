## 3. 收徒门（apprentice）

`meizhuang.h permit_recruit` 三条：叛出/背叛梅庄、`betrayer/times`、他派。
**与少林等门派不同**：`family == 日月神教` 或 `master_name == 东方不败` 时第三条不拦；
故新增 UCL 字段 `allow_families = ["日月神教"]` + `allow_master_name = "东方不败"`，
由 `SectMaster.recruit_gate?/3` 消费（缺字段老配置不变）。

东方不败弟子分支（`attempt_apprentice` 首段）本批按 LPC 状态落地：
- 丹青生/丁坚/秃笔翁：`set("move_party/日月神教--梅庄", 1)` 后 `return`（**不收徒**）；
  UCL `defer_family` + `defer_master_name` + `defer_mark` + `defer_msg`；
  引擎返回 `{:defer, msg, mark}`，`FamilyEvent` 写 `meta.marks` 后按 LPC 两句台词回显。
- 黑白子/黄钟公：同样置标记后**继续**常规门控；收徒成功后删标记并追加一句台词。
  UCL `defer_continue = true` + `delete_mark_on_accept = true` + `accept_msg`；
  引擎返回 `{:ok_with_mark, warning, mark}`。
- 限制：`move_party` 的跨门派传送/队伍语义在 ex 尚无消费端，见 GAP #874。

各 NPC 自门控（顺序即 LPC 顺序）：

| 丹青生 | `combat_exp >= 50000` →（`wuzheng-xinfa >= 80` **或** `xuantian-wujigong >= 80`） |

## 4. 绝招授受（10 条 `sect_master_grant`）

新增 `SectMaster.inquiry_grant/3` 分支 `gate_order = "lpc_meizhuang"`，严格按梅庄内联 `ask_skill*` 顺序：

```
已会(maxed) → 同门(family_deny) → 必修技能>=1(skill_deny) → 贡献(min_gongxian/gongxian_deny)
→ level_order 逐条(min_levels + level_deny) → {:ok, perform_id, cost}
```

该顺序与 `lpc_masterd` 的关键差异：技能存在门在贡献之前，且无 shen/neili/dex 门。
`level_order` 逐技能固定，避免「内功不足」与「招式火候不足」互换文案。

## 5. 日月神教直授技能（4 条 `ask_riyue`）

丹青生/黑白子/黄钟公/秃笔翁的 `ask_riyue()` 不走 `MASTER_D->teach_pfm`，而是：

1. 玩家 `family/family_name != 日月神教` → NPC `say 本庄只接待神教人士！`；
2. 玩家已有 `can_learn/meizhuang` → `say 你不是已经会了吗？还来找我干什么！`；
3. `say 恩，那好吧，我就教你<技能>。`；`set_skill(<技能>, 10)`；`set("can_learn/meizhuang", 1)`；
4. 若 `gongxian > 10000` **且** `balance > 100000000`（严格大于）：`add("gongxian", -10000)`、
   `add("balance", -100000000)`，并直接置本 NPC 对应的全部 `can_perform/...`；
5. `tell_object(me, 你学会了<技能>！\n)` + `say 下去好好练习吧。`

UCL 新增 `kind = "meizhuang_riyue"`；处理器落 `meta.marks["can_learn/meizhuang"]`、
`Stats.set_skill(..., 10)`、按配置 `Stats.learn_perform/2` 与扣贡献/钱庄铜钱
（LPC 1 银 = 100 铜，故 `balance 100000000` → `bank_coins 10000000000`）。
技能/绝招对照：泼墨披麻剑→`pomopima-jian/zui`；风雷盘法→`fenglei-panfa/fenglei`；
七弦无形剑→`qixian-wuxingjian/{yin,shan,zhu}`；石鼓打穴笔法→`shigu-bifa/{feng,shiyi}`。
