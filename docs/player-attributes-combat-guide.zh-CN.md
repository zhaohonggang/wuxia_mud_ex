# 角色属性与战斗机制指南

本文面向玩家，说明角色各项属性的作用，以及它们如何影响战斗结算。
所有公式与游戏内实现一致（对照 LPC combatd.c）。

---

## 一、三条状态线

状态栏格式：`[气血/上限气血 精/上限精 内力/上限内力]`，如 `[122/150气血 120/120精 200/200内力]`。

| 状态 | 作用 | 说明 |
|------|------|------|
| **气血 (qi)** | 生命值 | 战斗中被攻击扣减；**归零即死亡**，满血传回出生点 |
| **精 (jing)** | 心神 | 打坐的门槛（需 ≥70% 上限），只做门槛不消耗 |
| **内力 (neili)** | 真气储备 | 绝招、运功、加力的燃料；打坐可蓄到 **2 倍上限** |

每条线都有三层：

- **当前值**：实际拥有的量
- **max（上限）**：当前能达到的最高值
- **base（基础）**：天赋极限

受伤分两种：

- **直接伤害**：扣当前值，上限不动
- **创伤 (wound)**：削减 max 上限（如 max_qi 从 150 掉到 27），恢复缓慢向 base 回涨

自然回复：非战斗时每 15 秒回复一次，速度由根骨决定；战斗中回复效率降为 1/4。

## 二、四项先天属性

新角色四项均为 20。

### 膂力 (str) —— 攻击

- 决定**攻击当量**的放大倍数（见第五节公式）
- 命中后以 `膂力 + 加力` 作为伤害加成的起底
- 想打得痛 → 练膂力

### 身法 (dex) —— 防御与闪避

- 决定**防御当量**（闪避、招架判定都用它）的放大倍数
- 高身法有几率**完全卸掉一次攻击的伤害**：概率约 `(身法-10)/4 + 2 %`（20 点身法 ≈ 5%）
- 想躲得开、扛得稳 → 练身法

### 根骨 (con) —— 恢复与韧性

- 决定**自然回复速度**：每轮回复量含 `con×2+10`（气血）、`con+5`（精）
- 创伤上限回涨速度为 `con/2`
- 出招者的根骨越高，造成的创伤反而略轻（每高出基准 10 点约减伤 10% 创伤）
- 想续航久、创伤好得快 → 练根骨

### 悟性 (int)

预留属性，本期暂未接入结算（未来用于学习速度等），可先不关注。

## 四、技能体系

### 基本技能

| 技能 | 作用 |
|------|------|
| **unarmed 空手** | 不持武器时的攻击技能 |
| **sword 基本剑法** | 持剑时的攻击技能 |
| **dodge 轻功** | 闪避判定 |
| **parry 基本招架** | 招架判定 |
| **force 基本内功** | 内力上限、打坐效率、学习特技的门槛 |

### 有效等级与映射 (enable)

```
有效等级 = 基本等级 + enable 映射的特技等级
```

例：基本剑法 30 级 + enable sword 柳心剑法 40 级 → 攻击判定用 **70 级**的有效剑法。

```
enable sword liuxin-jian      # 柳心剑法映射到剑
enable parry liuxin-jian      # 也可映射到招架
enable force liuxi-neigong    # 柳溪内功映射到内功
```

映射决定你出招时使用哪门武功的**招式表**——柳心剑法的「杨柳依依」系列比通用拳脚强得多。

### 特技学习门槛

| 特技 | learn 门槛 | practice 支持 |
|------|-----------|---------------|
| 柳心剑法 liuxin-jian | 内功 ≥20 且 基本剑法 > 当前剑法等级 | ✅（耗气 55、内力 38） |
| 柳溪内功 liuxi-neigong | 基本内功 > 当前内功等级 | ❌ 只能学 |

### 绝招

**柳浪闻莺**（`perform liuxin-jian.liu`）：柳心剑法练到 60 级自动领悟。
消耗 80 内力，闪避 +等级/4、攻击 +等级/5，持续 `等级/6 + 10` 秒。

## 五、内力系统

### 内力上限

```
内力上限 = 基本内功/2 × 10 ＋ 已启用内功等级 × 10
```

例：基本内功 30 级启用柳溪内功 30 级 → 上限 = 150 + 300 = **450**。

### 打坐 (`exercise <数量>` / `dazuo <数量>`)

把气血按 1:1 转化为内力，每秒一跳，转化量随内功等级增长。
前置条件：非战斗中、已 `enable force`、精 ≥70% 上限。
内力蓄到 **2 倍上限** 时停止并尝试突破：成功则 `max_neili +1`，已达天花板则压回上限。

### 运功 (`exert powerup`)

消耗 100 内力，攻击、防御各提升 `内功等级/3`，持续 `内功等级` 秒。战斗中使用会忙乱 1~3 轮。

### 加力 (`jiali <0-N>`)

设一个持续开关：每次出招消耗 N 点内力，换取约 N 点额外伤害（内力不足自动停用）。打坐蓄力到 2 倍上限的内力正好用来加力。

## 六、战斗结算流程

战斗以 1 秒一轮的心跳推进。每一轮攻击的完整判定链：

```
1. 选招式        按等级加权随机（等级越高越容易出新招）
2. 闪避判定      AP/(AP+DP) 失败则命中
3. 招架判定      AP/(AP+PP) 失败则被打中
4. 伤害计算      武器伤害 + 力量加成 + 加力
5. 创伤结算      伤害 vs 护甲，可能削上限
6. 封顶折算      超高伤害递衰减半
```

### 第 2 步：闪避

- **AP（攻击当量）**：进攻方有效攻击技能算出
- **DP（闪避当量）**：防守方 dodge 技能算出
- 闪避概率 = DP/(AP+DP)
- **忙乱 (busy)** 中防御当量除以 3——运功走火、绝招后摇都会忙乱

### 第 3 步：招架

同款公式用 parry 技能。空手对持械方招架吃亏 10 当量，持械对空手占优 10。

### 第 4 步：伤害

```
基础伤害 = (apply伤害 + random(apply伤害)) / 2
       × (1 + 招式damage%/100)
伤害加成 = 膂力 + 加力(jiali)，再乘招式 force%
最终伤害 = 基础 + (加成 + random(加成)) / 3
```

- apply 伤害来自装备（武器 damage）与 NPC 配置
- 空手用 unarmed_damage，持械用 damage

### 第 5 步：创伤

```
候选创伤 = 最终伤害 - random(护甲armor)     # 约 1/2 概率生效
创伤再受攻方根骨减免
```

创伤削的是防守方**气血上限**，比直接伤害更难恢复。

### 第 6 步：封顶折算

单次伤害/创伤超过 200 的部分减半累进，超过 400 的部分再折四分之一。避免一击秒杀。

## 七、技能当量公式（进阶）

攻防判定用的核心公式（对应 LPC skill_power）：

```
当量 = (等级³/10 + 有效经验) / 30 × 相关属性
```

- 攻击判定乘 **膂力**，防御/闪避/招架判定乘 **身法**
- 有效经验边际递减：200 万以内全额计入，之后大幅缩水
- 等级低于 1 时退化为 `经验/2/30 × 属性`

**结论**：技能等级是三次方增长的主力，实战经验是线性补充，属性是全局放大器。三者缺一不可。

## 八、新手成长路线建议

1. **起步**：默认 60 级基本技能足够打野猪攒经验、潜能
2. **拜师**：找王重九学柳心剑法（先确保内功 ≥20）、柳溪内功
3. **enable**：把剑法和内功都映射上，出招立刻变强
4. **打坐**：攒内力推高 max_neili，解锁绝招和运功的燃料
5. **60 级**：领悟「柳浪闻莺」，配合 `jiali` 和 `exert powerup` 进入完整战斗循环

常用命令速查：`kill` `halt` `learn` `practice` `enable` `dazuo` `exert powerup` `jiali N` `perform liuxin-jian.liu` `score` `info`
