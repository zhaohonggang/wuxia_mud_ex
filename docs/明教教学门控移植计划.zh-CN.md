### 收徒结论（关键）
与神龙教**相反**：明教 7 位 F_MASTER 的 `attempt_apprentice` **均收徒**，各有独立多条件门
（permit_recruit → shen 下界 → 圣火心法 → 基本内功/轻功 → combat_exp → recruit）。
**无 `deny_all`**。收徒门全部可用既有字段表达（`permit_recruit` + `min_shen` +
`min_skills` + `recruit_skill_order` + `min_skills_deny` + `min_shen_deny` + `min_exp_deny`），
**无需新 gate_order**（默认 permit_first 顺序即 shen→skills→exp，与 LPC 一致）。

## 3. 引擎改动（2026-11-22 已落地）

原计划「零引擎改动」经复核为**错误**，实际需要两处小改动，均已实现并通过编译：

1. **`lib/kantele/sect_master.ex` `recruit_gate?/3`**：新增 `gate_order = "lpc_mingjiao"`
   分支，与 `lpc_xuanming` 共享「技能先于经验」门序。原因：默认 `permit_first` 先判经验
   （sect_master.ex:456）再判技能（:467），而明教 7 位师父 `attempt_apprentice` 是
   `shen → 圣火心法/附加技能 → exp`（技能先于经验）。若沿用默认门序，低经验高技能的
   玩家会得到错误的经验拒绝文案。
2. **`lib/kantele/world/loader.ex`**：`gate_order` allowlist 增加 `"lpc_mingjiao"`。
3. **`lib/kantele/sect_master.ex` `inquiry_grant_lpc/3`（lpc_masterd）**：同门门增加
   `no_family_check = true` 跳过分支，对应 `masterd.c` `free:1` 的 5 条张无忌绝招
   （混沌一阳/九曦混阳/金阳破岭/骄阳劈天/魔光日无极）。未配置该键的老门派零影响。

授艺门序选 `lpc_masterd`（而非原计划的 `lpc_kunlun`）：前者逐字镜像 `teach_pfm`
（`family → maxed → shen → gongxian → sk<1 → level_order → force → dodge → neili`），
且 `level_order` 有序链与 `max-neili` 伪键天然兼容；后者把 skill<1 放在 shen 之前，
与 LPC 不符。coagents 使用既有格式 `coagents = [{ id = "zhang wuji" startroom = "mingjiao:dadian" }]`。

**已回填**：11 个块全部完成；23 条 grant + 1 条 give_item + 7 位师父的
apprentice/teach/coagents/chat + 范遥 coagents/chat + 小昭 10 条问询静态化。
