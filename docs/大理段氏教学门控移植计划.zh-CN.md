## 2. 本批实现

### 2.1 teach 数据（14 NPC）

每个 NPC 的 `set_skill` 逐条落为 `teach = { family = "段氏皇族" teach_skills = {...} }`，
`max` = 该 NPC 自身该技能等级，`gongxian = 0`（与既有批次一致）。基本技能（force/dodge/
cuff/strike/sword/parry/finger 等）与专精技能（duanshi-xinfa/duanjia-jian/yiyang-zhi 等）
一并落入，因为 LPC 的 `set_skill` 全部对弟子可见（受 `valid_learn` 二次约束，不在此处理）。

段延庆/段誉虽无 `create_family("段氏皇族")`，但 LPC set_skill 存在；段誉属
`beiming-shengong/liumai-shenjian`（非段氏武学），按既有惯例保留 name/description 与 teach
数据落位，family 用其 LPC 师承（无则留空，仅作技能展示）。

### 2.2 十四条 `sect_master_grant`（perform_id）

全部走各 NPC **内联 ask_skillN**（非 `masterd.c teach_pfm`）。LPC 顺序为
「已会(can_perform) → 同门 → 必修技能≥1 → shen 下限(部分) → 贡献 → force → max_neili
→ 辅助技能(jingluo-xue) → 主技能等级」。`gate_order = "lpc_kunlun"` 的
`level_order` + `min_shen` + `min_gongxian` 可完整表达该顺序。

**门控顺序（`gate_order`）**：段氏 LPC 内联 ask_skill 的「贡献 vs 侠义」顺序**逐招不同**：
- 5 条走 `lpc_duan`（贡献先于侠义/负神门）：段正淳「惊天一剑」、段正明「五绝连环 /
  神指点穴 / 一指乾坤」、一灯大师「阳关三叠」。其中「惊天一剑 / 五绝连环」带
  `min_shen = 0`（对应 LPC `shen < 0` 负神门），其余三条带正 `min_shen`。
- 其余 9 条走 `lpc_kunlun`（侠义先于贡献，或无侠义门）：段正淳 sk1-3、段正明「起死回生」、

  贡献之前，`lpc_kunlun` 的 `min_shen = 0` 正好表达该顺序。

引擎既有 `lpc_kunlun` 路径固定「侠义先于贡献」，与 LPC 不符。本批新增**向后兼容**的
`gate_order = "lpc_duan"`（`sect_master.ex` 新增 `inquiry_grant_duan/3`，与
`inquiry_grant_kunlun/3` 同构但把 `gongxian` 检查移到 `min_shen` 之前），供「贡献先于侠义」
的招式使用；「侠义先于贡献」的招式沿用 `lpc_kunlun`。两条路径互不干扰，昆仑/天地会既有
配置零影响。

> `yideng` 先天功乾阳剑气的同门门是「全真教 或 段氏皇族」双门派（LPC `ask_skill2`），
> 而引擎 family 校验是单值 → 用 `gate_order = "lpc_kunlun"` 时 family 只填「段氏皇族」会
> 误拒全真教玩家。见缺口 #845。

### 2.3 apprentice 门控（duan.h permit_recruit + duanzm）

`duan.h permit_recruit`：`detach/段氏皇族` 或 `betrayer/段氏皇族` → 拒；`betrayer/times`
→ 拒；`born_family != "段氏皇族"` →「我们段家乃皇族出身，不收外人」；
已入他派 → 拒。引擎无 born_family 门（只有 family/permit_recruit），故：

- 11 个 recruit NPC：`permit_recruit = true`、`family = "段氏皇族"`、逐字 `family_deny`/
  `betray_sect_deny`/`betray_times_deny`/`other_family_deny`。**born_family 硬门缺失**
  → 见缺口 #843。
- `duanzm`（段正明）额外三门（LPC 顺序 permit_recruit → `shen<50000` →
  `duanshi-xinfa<100` → `combat_exp<400000`）：`gate_order = "lpc_xuanming"`（引擎中唯一
  「技能先于经验」路径）、`min_shen = 50000`、`min_skills = {duanshi_xinfa=100}`、
  `min_exp = 400000`，逐字 deny（`治好国家？` / `段氏的面子`）。
- `yideng.c` / `duanyq.c` / `duanyu.c` 无 attempt_apprentice → 不写 apprentice。

### 2.4 脉经 give_item（duanzm.c:347-450）

段正明两本脉经（王叔和脉经 / 玉颧神脉经）的 ask 分支含 owner 遍历 + 5 段文案 +
「shen<10000/80000」「exp 太浅」「jingluo-xue 已通达」等门，属于 masterd give_item
持有者遍历同类机制（#820）。本批保留为文本 inquiry 占位并标注 GAP，**不伪造简化逻辑**。
→ 见缺口 #844。
