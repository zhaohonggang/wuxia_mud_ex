## 2. 本批实现

### 2.1 teach 数据（14 NPC）

每个 NPC 的 `set_skill` 逐条落为 `teach = { family = "段氏皇族" teach_skills = {...} }`，
`max` = 该 NPC 自身该技能等级，`gongxian = 0`（与既有批次一致）。基本技能（force/dodge/
cuff/strike/sword/parry/finger 等）与专精技能（duanshi-xinfa/duanjia-jian/yiyang-zhi 等）
一并落入，因为 LPC 的 `set_skill` 全部对弟子可见（受 `valid_learn` 二次约束，不在此处理）。

段延庆/段誉虽无 `create_family("段氏皇族")`，但 LPC set_skill 存在；段誉属
`beiming-shengong/liumai-shenjian`（非段氏武学），按既有惯例保留 name/description 与 teach
数据落位，family 用其 LPC 师承（无则留空，仅作技能展示）。

### 2.3 apprentice 门控（duan.h permit_recruit + duanzm）

`duan.h permit_recruit`：`detach/段氏皇族` 或 `betrayer/段氏皇族` → 拒；`betrayer/times`
→ 拒；`born_family != "段氏皇族"` →「我们段家乃皇族出身，不收外人」；
已入他派 → 拒。引擎无 born_family 门（只有 family/permit_recruit），故：

- 11 个 recruit NPC：`permit_recruit = true`、`family = "段氏皇族"`、逐字 `family_deny`/
  `betray_sect_deny`/`betray_times_deny`/`other_family_deny`。**#843 已补**
  `required_born_family = "段氏皇族"` + `born_family_deny = "我们段家乃皇族出身，不收外人。"`，
  与 `duan.h:17-22` 逐字一致；引擎门序也已改为「叛门 → 叛师 → 出生门 → 他派」。
- `duanzm`（段正明）额外三门（LPC 顺序 permit_recruit → `shen<50000` →
  `duanshi-xinfa<100` → `combat_exp<400000`）：`gate_order = "lpc_xuanming"`（引擎中唯一
  「技能先于经验」路径）、`min_shen = 50000`、`min_skills = {duanshi_xinfa=100}`、
  `min_exp = 400000`，逐字 deny（`治好国家？` / `段氏的面子`）。
- `yideng.c` / `duanyq.c` / `duanyu.c` 无 attempt_apprentice → 不写 apprentice。

### 2.4 脉经 give_item（duanzm.c:347-450）· 已补 #844

两本脉经改为真实 `kind = "give_item"`，按 LPC 原序：
门派 → 师父（`master_before_gates = true`）→ shen → combat_exp → jingluo-xue 上限
→ owner 四分支 → NPC say + give。王叔和脉经 10000/10000/149，玉颧神脉经
80000/300000/199；两本书自身的 `meta.book.max_skill` 仍保留 LPC 原值 149/250，
不得与 ask 分支的 199 混用。

- 新增两件物品 `clone_lib:jingluoxue1` / `jingluoxue2`，逐字保留 unit/value/weight/
  material/no_sell 与 book 的 skill/exp_required/jing_cost/difficulty/min_skill/max_skill。
- owner 四分支文案逐字落地：本人 / 借出容器 / 段氏同门 / 外人。LPC 只有「同门」与
  「外人」两支，`owner_ally_deny` 在配置中与外人同文（不可达分支，不伪造新语义）。
- LPC `command("say ...")` 用新增 `npc_say` 广播；因原函数 return 1 后无私发返回值，
  同步新增 `silent_success = true` 抑制 give_item 缺省私聊。两个字段均为 opt-in，
  其它 give_item 配置零回归。
