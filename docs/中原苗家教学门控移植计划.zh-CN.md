## 3. 收徒门（apprentice）

### 3.1 苗人凤 born_family 硬门（GAP #843 苗家分支）
`miao.h permit_recruit` 三条（顺序即 LPC）：
1. `detach/中原苗家` 或 `betrayer/中原苗家` → `heng` + `say 你反复无常，我不能收你为徒！`
2. `born_family != "中原苗家"` → `hmm` + `say 我苗家向来便不收容外人。`
3. 已入他派（`family/family_name` 存在且 != 中原苗家）→ `hmm` + `say 你既已在外面投师学艺，就应有所作为，又跑回来作甚？`

ex 引擎 apprentice **无 born_family 字段**，需扩展：
- `parse_apprentice/1` 新增 `required_born_family`（字符串）+ `born_family_deny`（文案）；
- `SectMaster.recruit_gate?/3` 在 permit_recruit 之后、性别/经验之前插入 born_family 硬门分支：
  `required_born_family` 非空且 `student_born_family(student) != required_born_family` → `{:error, born_family_deny}`。
- `student_born_family/1` 从 `meta.env.born_family`（atom/string 双读）读取。
- 老配置无此 key → 恒不命中，零回归。段氏 #843（段/胡/欧阳/慕容世家）同用此字段，一并解决。

苗人凤 apprentice 配置：
```
apprentice = {
  family = "中原苗家"
  required_born_family = "中原苗家"
  born_family_deny = "我苗家向来便不收容外人。"
  permit_recruit = true
  betray_sect_deny = "你反复无常，我不能收你为徒！"
  other_family_deny = "你既已在外面投师学艺，就应有所作为，又跑回来作甚？"

```

苗人凤 `attempt_apprentice` 另有**姓名门**（ permit_recruit 通过后）：
