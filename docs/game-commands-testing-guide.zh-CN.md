# 游戏命令测试指南（新手 admin 版）

> 面向第一次进游戏做验收的管理员。按本文场景从上到下走一遍，
> 即可覆盖当前版本全部玩家可见命令与主要系统链路。
> 编写时间：2026-08-25。命令实现以 `lib/kantele/character/commands.ex`
> 与 `commands/` 目录为准；本文与代码不符时以代码为准。

---

## 一、准备与进入游戏

1. 确认容器在跑：宿主机执行 `docker ps`，应看到
   `wuxia_mud_dev-app-1` 与 `wuxia_mud_dev-db-1`。
2. 浏览器打开 `http://localhost:4000/_health`，应返回
   `{"status":"OK","world":"ok",...}`。
3. 进入游戏二选一：
   - **Web**：登录网站（admin@example.com / password）→ 打开
     `http://localhost:4000/client/play`；
   - **Telnet**：`telnet localhost 4646`。
4. 游戏内登录三步（密码**不校验**，随便输）：

   ```text
   用户名：grant        ← 任意非空字符串（输入 quit 则断开）
   密  码：123          ← 任意
   角色名：阿福          ← 新名字即新建角色；老名字会读回存档
   ```

5. 登录成功会看到房间描述与 `[气血150/150 ...] >` 提示符。
   输入 `look` 可随时重看当前房间。

> 提示：想每次都拿全新号测流程，就换个没用过的角色名；
> 想验证存档恢复（等级/铜钱/背包），就复用老角色名重新登录。

## 二、地图速览与行走

```text
 [萨玛蒂镇]                     [柳溪镇]
  城镇广场 Town Square           山路 shanlu（黑虎，主动攻击）
   ├ west→ 铁匠铺                 └ north→ 镇广场 guangchang（野猪、阿婆）
   ├ north→ 市场                  ├ west→ 练武场 lianwuchang（王重九，师父）
   └ east→ 客栈                   └ east→ 张记铁铺 tiepupu（店小二，商人）
```

出生点固定在萨玛蒂城镇广场。行走命令（英文 / 单字母 / 中文）：

| 方向 | 命令 | 单字母 | 中文 |
|---|---|---|---|
| 北 | north | n | 北 |
| 南 | south | s | 南 |
| 东 | east | e | 东 |
| 西 | west | w | 西 |
| 上 | up | u | 上 |
| 下 | down | d | 下 |

常用路线（每条都是连续输入的方向序列）：

| 目的地 | 路线 |
|---|---|
| 张记铁铺（商店/问询） | `w` `n` `n` `e` |
| 练武场（拜师学艺） | `w` `n` `n` `e` `w` `w` |
| 柳溪镇广场（野猪/阿婆/任务） | `w` `n` `n` |
| 山路（黑虎，危险） | 柳溪镇广场 `s` |

## 三、命令总表（按类别）

### 信息与帮助
| 命令 | 说明 |
|---|---|
| `look` / `l` / `看` | 重看当前房间（人物/物品/出口/小地图） |
| `score` | 自我状态总览（气血/四维/经验/潜能/铜钱/阅历威望贡献） |
| `info` | 武学与属性明细（含技能等级与映射特技） |
| `map` | 当前区域小地图 |
| `who` | 在线玩家列表 |
| `version` | 游戏版本号 |
| `help` | 帮助索引；`help <主题>` 查看单篇（现有主题：say / whisper / welcome） |
| `commands`（或 `命令`） | 列出全部玩家可见命令及一句说明 |

### 移动与探索
| 命令 | 说明 |
|---|---|
| 方向命令 | 见第二节表格 |
| `emotes` | 预置表情列表（当前有 smile / wave / frown） |
| `smile` / `wave` / `frown` | 直接以表情名作为命令做出动作 |

### 物品
| 命令 | 中文 | 条件 |
|---|---|---|
| `get <物品>` | `拿`/`捡` | 物品在当前房间地上 |
| `drop <物品>` | —（中文"扔"未实现） | 物品在背包 |
| `inventory`（简写 `i`/`inv`) | — | 无 |
| `wield <武器>` | — | 背包内有武器类物品 |
| `unwield <武器>` | — | 已装备该武器 |
| `wear <护甲>` | `穿` | 背包内有护甲类物品 |
| `remove <护甲>` | `脱` | 已装备该护甲 |
| `eat <食物/丹药>` | `吃` | 背包内、verbs 含 eat |
| `drink`（`heal`/`喝药`/`喝`） | — | 背包有药水（新手自带一瓶），回气血80/内力50 |

### 社交
| 命令 | 说明 |
|---|---|
| `say <话>` | 房间说话（支持 `@某人` 点名、`>副词` 修饰） |
| `general <话>` | general 频道喊话，全服在线可见 |
| `tell <人> <话>` | 私聊指定玩家 |
| `reply <话>` | 回复最近私聊你的人 |
| `whisper <人> <话>` | 房间内低声耳语 |
| `emote <文本>` | 以第三人称播出动作文本 |
| `ask <人> <关键词>`（中文 `问`） | 向 NPC 问询，命中其问答表即回话 |

### 战斗
| 命令 | 中文 | 说明 |
|---|---|---|
| `kill`/`fight <目标>` | `杀掉`/`杀 <目标>` | 开战（目标须在同房间且存活） |
| `halt` | — | 停手脱离战斗 |
| `perform 武功.招式`（如 `perform liuxin-jian.liu`） | — | 绝招，有技能门槛（未达门槛提示"谈何施展"） |
| `jiali <0-N>` | — | 加力档位：耗内力换伤害；上限=enable的内功等级÷2；0 关闭 |

### 养成
| 命令 | 中文 | 条件与消耗 |
|---|---|---|
| `apprentice <师父>` | `拜师` | 对方带门派教学配置（如练武场王重九）；成功后记入师门 |
| `learn <技能> <师父>` | `学` | 已拜师对象在场；潜能 −2/级；徒弟不能超过师父该项等级 |
| `practice <技能>` | `练` | 消耗气与内功（柳溪内功只能 learn 不能 practice） |
| `enable <用法> <特技>` | — | 如 `enable force liuxi-neigong` 映射内功 |
| `exert powerup` | — | 运功加攻，消耗内力；持续中重复施放会被拒 |
| `exercise <耗气量>` / `dazuo` | `打坐` | 见第六节打坐条件 |
| `pai`（或 `门派`） | — | 门派信息：师承/贡献/阅历/威望/正邪 |

### 商店·任务·问询
| 命令 | 说明 |
|---|---|
| `list [商人]` | 列出货单（不指名则全场商人应答） |
| `buy <物品>`（中文 `买`） | 商人报价后自动成交：扣铜钱、物品入包；钱不够被拒 |
| `ask <人> <关键词>`（中文 `问`） | 关键词包含匹配 NPC 问答表；阿婆处可交付任务 |

### 系统（内部/dev 命令，不在 commands 列表中）
| 命令 | 用途与风险 |
|---|---|
| `quit` | 退出游戏断开连接（存档已实时落盘，重登读回） |
| `world_status` | 查询上次世界加载结果（时间/成败/原因/文件）；排障用 |
| `reload` | 热更：重编译 Elixir + 重新解析全部 UCL 并原地更新世界；加载失败会回执失败原因且旧世界照常运行 |
| `recompile` | 仅重编译代码不重载世界数据 |
| `delay <秒> <命令>` | 延时执行（内部机制命令，一般不用直接测） |

## 四、分场景实操脚本

> 每个场景独立可测，按序做完整覆盖最顺。
> 「预期」给出判定用的关键输出片段。

### 场景 A：新号出生与信息命令
```text
score        预期：气血 150/150、实战经验 1000、潜能 100、铜钱 100文
who          预期：列出自己
version      预期：版本号
commands     预期：命令清单（约 30 条，含一句中文说明）
help         预期：帮助主题索引
help say     预期：say 主题内容
info         预期：四维 20、基本拳脚/剑法 60 级、基本内功 20 级等明细
look         预期：城镇广场描述 + 出口 south/north/west
```

### 场景 B：行走与中文别名
```text
北           预期：走到市场；同时验证中文方向可用
南           预期：回到城镇广场
北上         预期：报未知命令（词边界生效，不误触发移动）
w            预期：到铁匠铺
e            预期：回城镇广场
```

### 场景 C：物品拾取与装备（在张记铁铺）
路线：`w` `n` `n` `e`
```text
get 长剑      预期：拾取提示
i            预期：背包出现长剑
wield 长剑    预期："抽出长剑"之类装备文案
get 布袍 → wear 布袍                    预期：穿上布袍
穿 布袍（先 remove 布袍 再试中文别名）    预期：再次穿上门派前缀正常
drop 包子     （若无包子先跳过）          预期：丢弃提示
```

### 场景 D：商店购物与进食（张记铁铺）
```text
list 店小二   预期：货单（包子15/培元丹100/长剑300/布袍50 文）
买 包子       预期："你从店小二手里买下包子…花了 15 文铜钱"
eat 包子      预期："你吃下包子…" 且背包少一个
score         预期：铜钱变为 85 文
喝药          预期：（受伤状态下）气血+80 内力+50；满血也可服用
```

### 场景 D2：四维成长丹（A7 核心验收，需先凑铜钱）
培元丹 100 文，场景 D 买完包子只剩 85——先给测试号充铜钱（admin 测试手段）：
```powershell
docker exec wuxia_mud_dev-db-1 psql -U postgres -d ex_venture_dev -c ^
  "UPDATE character_metadata SET coins=500 WHERE character_id=(SELECT id FROM characters WHERE name='阿福')"
```
（角色名换成实际登录的角色；改完需重新登录该角色读回存档）
```text
买 培元丹      预期：扣 100 文，培元丹入包
eat 培元丹     预期："一股热气涌向四肢百骸。（气血+50 臂力+1）"
score          预期：臂力 20 → 21
再吃培元丹×10  预期：臂力一路 +1 到 30 后，
               "你服药已多，臂力再难精进，药力全然吸收不了。"（软上限 30 拒绝消耗）
```
（吃满上限需 10 颗共 1000 文，嫌麻烦可只验证前两步 + psql 把 coins 改 2000 再连吃）

### 场景 E：问询与闲聊
```text
问 店小二 柳溪   预期：店小二 tell 你柳溪镇介绍
问 店小二 黑虎   预期：黑虎背景故事
ask 店小二 about 玉牌   预期：玉牌传闻引导
say 大家好       预期：房间说话回显
general 测试频道  预期：[general] 开头的频道回显
wave            预期：挥手动作广播
```

闲聊（A10/N3）是概率触发（野猪 8%），无命令——在野猪所在房间多停留
半分钟到一分钟，应能看到"野猪用鼻子拱了拱地面。"之类的台词随机出现。

### 场景 F：拜师学艺（练武场）
路线：`w` `w`
```text
apprentice 王重九    预期：「好，从今日起你便是柳溪派门下弟子」
pai                 预期：门派：柳溪派 / 师父：王重九 / 贡献 0
learn force 王重九   预期："你的基本内功进步了！"（潜能 -2）
learn liuxi-neigong 王重九   预期：学会柳溪内功
enable force liuxi-neigong   预期：映射成功
exert powerup        预期：运功 buff 生效；再输一次提示已在运功中
practice sword       预期：消耗气/内力，剑法进步
jiali 3              预期：若柳溪内功≤1级提示"最多加力 0 档"；学到 6 级后再设可成功
```

### 场景 G：打坐修炼（注意房间限制）
```text
dazuo 30             在练武场输入 → 预期："无法在这个地方安心打坐"（no_fight 房）
e                    回镇广场
打坐 30              预期："盘膝坐下…"，数十秒后"运功完毕"
                     或（首次大概率）"你的内力修为似乎已经达到了瓶颈。"
score                预期：内力上限可能 +1（当内力蓄满 2×上限且未到瓶颈）
```

**⚠️ 瓶颈是初始状态的正常预期**：新号 max_neili=200，而刚学 1 级柳溪内功时
天花板只有 基本内功÷2×10＋特殊内功×10 = 20÷2×10＋1×10 = **110**，
200 ≥ 110 → 打坐必现瓶颈提示。想亲眼看到"你的内力增加了！！"：
先 `learn liuxi-neigong 王重九` 把柳溪内功学 to **11 级以上**
（天花板 = 100＋等级×10 > 200，需 11 次 learn 共 22 潜能，新号潜能 100 足够），
再打坐即可逐次 +1。

打坐前置条件（任一不满足会被拒并提示原因）：
参数≥10、非战斗中、已 enable 内功、精力≥70%、非禁斗(no_fight)房间。
内力天花板 = 基本内功÷2×10 + enable的特殊内功×10，到瓶颈会明确提示。
打坐中若被卷入战斗会自动中断（"你将真气压回丹田，站了起来"），
内力钳回 2×上限——单人验证可在打坐时另开一窗口令野猪攻击自己。

### 场景 H：战斗全流程
```text
（柳溪镇广场）
kill 野猪        预期：战况播报数轮后"你杀死了对手，获得 X 点实战经验、Y 点潜能"
score            预期：经验/潜能增加；铜钱可能增加 5~15 文（击杀掉落）
s                到山路
kill 黑虎        预期：黑虎很强，大概率被打死 → "慢慢睁开眼睛，清醒了过来" 并回到出生点
wield 长剑       预期：重生后重新装备（死亡不掉装备）
```

黑虎是主动怪：站在山路上它会主动开战；逃跑用 `halt` 后立刻往反方向走。

记仇（A9/P11）：与野猪开战几轮后 `halt` 停手走开再回来——aggressive 怪
会再次主动扑向你，且优先攻击打过它的人（attacked_by 记忆，内存态，
NPC 死亡/重载后清空）。

## 五、常见失败文案对照

| 提示 | 原因 |
|---|---|
| 你要跟谁动手？ | kill 未带目标名 |
| 这里没有 XX 这个人。 | 目标不在本房间或名字不符 |
| 此处乃习武清修之地，不可动手。 | 当前房间是 no_fight（练武场） |
| 你必须先用 enable 选择要运用的内功心法。 | 打坐/加力前未映射内功 |
| 你的内功还没有达到那个境界！ | dazuo 参数小于 10 |
| 你现在的气太少了… | qi 低于打坐耗气量 |
| 你现在精不够… | 精力低于七成 |
| 无法在这个地方安心打坐。 | no_fight 房间禁止打坐 |
| 你的内力修为似乎已经达到了瓶颈。 | 内力已达当前天花板，需先升内功等级 |
| 你还没用 enable…无法加力。 | jiali 前未映射内功 |
| 最多加力 N 档。 | 超过 enable内功等级÷2 |
| 这里不卖 XX。 | 该商人的 goods 里没有此物 |
| 你身上的钱不够… | 铜钱低于售价 |
| 你身上没有这样东西。 | eat/drop 找不到背包物品 |
| 你是个文盲/谈何施展 之类门槛提示 | perform 技能等级未达标 |

## 六、已知限制与备注

- `jing`（精力）目前只随根骨自然回复，无消耗途径（b 期 learn 耗精后才激活）。
- 死亡无惩罚：满血回出生点、装备背包保留。
- `reload` 会终止并重建全部 NPC——正在进行的战斗会被打断，属预期行为。
- 世界数据改动（data/*.ucl）后用 `reload` 生效；改 lib 代码需重启容器。
- 自动化回归：`scripts/combat_e2e.exs`（战斗闭环）、
  `scripts/phase_a_e2e.exs`（a 期各系统 19 项断言），
  运行方式见各脚本头部注释。
