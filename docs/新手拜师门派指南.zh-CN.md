# 新手拜师门派指南

本文档列出当前游戏中新手可以拜师加入的门派、加入条件、可学习武功、以及师父所在的位置。数据来源于 `data/world/*.ucl` 中的 `teach`、`apprentice`、`inquiries` 块，以及 LPC 源码 `kungfu/class/` 中的 `set_skill`、`attempt_apprentice`、`ask_skillN()` 数据，已全部回填到 UCL 中。

## 7. LPC 拜师实现与 UCL 配置对比

本节对照 LPC 源码 `kungfu/class/*/*.c` 中的 `attempt_apprentice(object ob)` 实现，逐一核验各师父 NPC 在 UCL `apprentice` 块中的收徒门槛是否对齐，并列出已知差异。

### 7.1 字段映射 (LPC → UCL)

| LPC 检查项 | UCL 字段 | 说明 |
|------------|----------|------|
| `permit_recruit(ob)` | — | 基础门控（已加入、正在战斗等），UCL 侧由 `attempt_apprentice/3` 统一处理，不在 `apprentice` 块体现 |
| `query("shen")` 比较 | `min_shen` / `max_shen` | 侠义值下限/上限 |
| `query("combat_exp")` 比较 | `min_exp` | 战斗经验下限 |
| `query_skill(skill, 1)` 比较 | `min_skills` | 技能等级下限 |
| `query("class")` 比较 | `class` | 职业门限 |
| `query_int()` / `query("max_neili")` | — | **UCL 暂不支持**，见 §7.3 差异清单 |
| `command("recruit ...")` | — | 正式收徒动作，UCL 侧由 `Kantele.Character.Family.attempt_apprentice/3` 执行 |

### 7.2 各师父 LPC 实现详表

#### 俞莲舟 — 武当派 (`kungfu/class/wudang/yu.c`)

LPC 检查项（按顺序）：
1. `permit_recruit(ob)`
2. `shen >= 20000`
3. `combat_exp >= 150000`
4. `wudang-xinfa >= 80`
5. `taoism >= 80`
6. 收徒后若 `class != "taoist"` 则设为 `taoist`

UCL `apprentice` 块 (`data/world/signature.ucl`，characters "yulianzhou")：
- `family = "武当派"`, `min_shen = 20000`, `min_exp = 150000`, `min_skills = { wudang_xinfa = 80, taoism = 80 }`, `class = "taoist"`

**一致性**：✅ 完全对齐。

| 5 | 陈家洛 / 红花会 | `max_neili >= 2000` | `apprentice` 块无内力上限字段 | 若需严格对齐，可补充 `min_max_neili = 2000`（需侧支持）或标注备注 |
| 6 | 王重九 / 柳溪派 | 无 LPC 源码 | 无 `apprentice` 块 | ⏸ 待 LPC 源码或人工确定门槛 |

### 7.4 结论

10 位有 LPC 源码的师父 NPC 中，数值门槛（shen/exp/skill/class）均已在 UCL `apprentice` 块中回填并对齐；其余差异集中在：
- **UCL 尚未支持的 LPC 字段**：`query_int()`（悟性）、`max_neili`（内力上限）；
- **逻辑算子差异**：刘处玄、桑三娘的 OR 关系在 UCL 中表现为 AND（门槛略高，安全偏差）；
- **额外增加的门槛**：苗人凤的 `miaojia_neigong >= 50` 在 LPC 中不存在；
- **未落地的师父**：柳派王重九无 LPC 源码，亦无 UCL `apprentice` 块。

上述差异均不影响现有拜师功能的正确性，仅为 LPC 与 UCL 的保真度差异，可按需逐项补齐。

## 9. 少林派 (Shaolin Sect) — LPC 加入与学习路径（详细对齐）

### 9.1 概述

少林派是 sects.ex 中的主门派原型，但第 2 节「详细门派条目」目前**尚未**有少林派的固定师父条目。少林派在 LPC 源码中实现了一套**辈分制 + 推荐信 + 斗武**的加入机制，与其他门派的简单 `apprentice` 数值门槛完全不同。下面按 LPC 源码 `kungfu/class/shaolin/*.c` 完整梳理。

**数据来源**：`/kungfu/class/shaolin/` 下的 NPC 源码，包括 `da-mo.c` (达摩祖师)、`jue-yuan.c` (觉远)、`wuming.c` (无名老僧)、`xuan-nan.c` (玄难大师) 以及 `cheng.h`、`dao.h`、`qing.h`、`du.h`、`hui.h`、`xuan.h` 等共享头文件。

**门派标识**：`create_family("少林派", <辈分>, <称号>)`  
**职业**：`bonze`（出家人，俗家弟子不可在寺内学艺）  
**核心武功**：`hunyuan-yiqi`、`shaolin-shenfa`、`nianhua-zhi`、`sanhua-zhang` 等  
**no_teach**：`shaolin-jiuyang`（达摩祖师，走特殊路径，不走 perform_id 管道）

---

### 9.2 入门总体流程（三步走）

少林派入门分三个阶段：

1. **成为少林派辈分 0 弟子**（打杂僧人阶段）
2. **通过推荐信系统拜入长老为师**（辈分晋升，需斗武）
3. **达摩祖师高门槛收徒**（生辈/渡字辈，门槛极高）

---

### 9.3 第一阶段：成为少林派（辈分 0）

#### 觉远 (生辈分 0, 打杂僧人) — `kungfu/class/shaolin/jue-yuan.c`

- `attempt_apprentice`：**直接拒绝收徒** ("贫僧乃带罪之身，岂能收徒")，不可从觉远处正式拜师。
- 但可通过**交还《楞伽经》(lengjia jing)** 获得学习「少林九阳功」(shaolin-jiuyang) 的资格 (`can_learn/jiuyang-shengong/shaolin`)，并可学习 `shaolin-jiuyang`。
- 这不是正式拜师，而是传授武功。

#### 无名老僧 (生辈分 0, 打杂僧人) — `kungfu/class/shaolin/wuming.c`

- `attempt_apprentice`：
  - 若玩家**已是少林弟子**：传授 `ruying-suixingtui` (如影随行腿) 和 `rulai-zhang` (千手如来掌) 的基础。
  - 若非少林弟子：说"我只是少林的一名扫地僧，哪里懂什么武功"，**不收**。
- `recognize_apprentice`：要求少林弟子、`shen >= 50000`，仅教 `strike`/`unarmed`/`rulai-zhang`/`ruying-suixingtui`，且等级上限 179。
- `ask_skill1`：**「万佛朝宗」**(rulai-zhang 绝招)，要求 `gongxian >= 800`、`shen >= 150000`、`force >= 350`、`rulai-zhang >= 220`，扣 800 贡献。
- `accept_ask`：传授「如影随形」(ruying-suixingtui 绝招)、「避云遮日」(jiasha-fumogong 绝招)。

> 觉远和无名都是辈分 0 的"打杂僧人"，不负责收新入门弟子，只对已是少林弟子传功。

---

### 9.4 第二阶段：推荐信系统与辈分晋升

少林派各字辈长老共享一套 `attempt_apprentice` 逻辑（定义在 `cheng.h`、`dao.h`、`qing.h` 等头文件中），核心检查项（按顺序）：

| 检查项 | 说明 |
|--------|------|
| `permit_recruit(ob)` | 基础门控（已加入、正在战斗等） |
| `family_name == "少林派"` | 玩家必须已是少林派弟子 |
| `class == "bonze"` | 须为出家人，俗家弟子不可在寺内学艺 |
| `ob_fam["generation"] == 0` | 直接收为弟子（新入门者） |
| `ob_fam["generation"] <= my_fam["generation"]` | 拒绝（辈分不够，"贫僧哪里敢当"） |
| `ob_fam["generation"] == my_fam["generation"] + 1` | 直接收（同门师辈的徒弟过来） |
| `ob_fam["generation"] == my_fam["generation"] + 2` | 需持有推荐信 (`apprentice_ok`)，改名为对应字辈 |

#### 推荐信 + 斗武流程（以清字辈 qing.h 为例）

1. 玩家持 `damo ling` (达摩令) 且辈分符合 → NPC 设 `fight_ok`
2. 与 NPC **斗武**，NPC 气血降至 50% 以下 → 胜利，获得 `tuijian xin1` (推荐信1)
3. 将推荐信交给 NPC → 设 `apprentice_ok`
4. `attempt_apprentice` 检查通过 → 收徒，改名为 `清` + name[1..1] (清字辈)

同理适用于：
- **道字辈** (`dao.h`, 辈分 39)：推荐信 `tuijian xin2`，改名为"道"字辈
- **澄字辈** (`cheng.h`, 辈分 37)：推荐信 `tuijian xin4`，改名为"慧"字辈

> 斗武胜利条件：NPC 气血比例 <= 50%（即玩家需将 NPC 打至半血以下）。

#### 各字辈 NPC 对照表

| 辈分 | 字辈 | 代表 NPC 文件 | 推荐信 | 改名前缀 |
