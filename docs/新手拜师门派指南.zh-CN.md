# 新手拜师门派指南

本文档列出当前游戏中新手可以拜师加入的门派、加入条件、可学习武功、以及师父所在的位置。数据来源于 `data/world/*.ucl` 中的 `teach`、`apprentice`、`inquiries` 块，以及 LPC 源码 `kungfu/class/` 中的 `set_skill`、`attempt_apprentice`、`ask_skillN()` 数据，已全部回填到 UCL 中。
