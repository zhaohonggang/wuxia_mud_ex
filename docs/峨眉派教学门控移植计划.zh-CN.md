## 0. 门派顺序与「部分回填」辨析

按上一批（duan / 大理段氏）完成后确立的门派顺序，下一个字母序门派是 **emei**。

emei 不是「完全零回填」：#691 曾给 `emei_miejue` 加过 `teach` / `apprentice`，zone 文件
`emei.ucl` 也已有 `daoming` 角色。但审计发现旧 `teach` 块严重偏离 LPC：

- `max = 60`、`gongxian = 2/3` 为**无 LPC 来源的编造值**（LPC `miejue.c` 全部 `set_skill`
  为 200-260，且类库无 emei skill 的 gongxian 收费表）；
- 只收 11 个技能，LPC 有 25 个；`no_teach = ["emei-jiuyang"]` 倒是对应真实 LPC 门。

本批按项目宪章「ex ≥ lpc」修正该块，不保留简化版本。

## 2. 本批实现（Task #849）

### 2.1 teach / no_teach

- 24 个 `clone_lib` 的 `emei_*` NPC 全部写 `teach = { family = "峨嵋派" teach_skills = {...} }`，
  `max` 取该 NPC LPC `set_skill` 原值，`gongxian = 0`（与 duan / 既有批次一致）。
- `no_teach` 逐字来自 LPC `set("no_teach", ...)`：13 个 NPC 有该项，`zhou` 有 6 项。
- `emei_miejue` 旧块重写：25 技能原值 + 0 贡献；保留 `no_teach = ["emei-jiuyang"]`。
- `emei.ucl` 的 `daoming` 补 4 技能 teach（该文件单独校验）。

### 2.2 apprentice（emei.h + 逐 NPC）

`emei.h permit_recruit` 顺序：性别女性 → detach/betrayer → betrayer/times → 他派 →
师父是 bonze 时学生必须 bonze → `shen >= 0`。映射：

- `gender = "女性"`、`gate_order = "gender_first"`（性别先于 permit_recruit）；
- `permit_recruit = true` + 三句逐字 deny；
- bonze 师父（dao/feng/fengling/he/hui/jia/kong/miejue/xian/xin/xu/xuan/zhao/zhen）
  加 `require_class = "bonze"` + `class_deny` 逐字；
- 逐 NPC 额外门：`min_shen` / `min_exp` / `min_skills`，默认引擎顺序
  「shen → exp → skills」与 LPC 完全一致；
- 四个小师太无 attempt_apprentice → 不写 apprentice。

### 2.5 九师太剃度 / kneel（`tobebonze.h`，#853）

LPC `kungfu/class/emei/tobebonze.h` 由 12 个 NPC 文件 include，但只有 9 个把
「剃度/出家」注册给 `ask_for_join()`：静慧/静迦/静空/静闲/静心/静玄/静虚/静照/静真。
静道、静风、静和虽 include 该头文件，却未暴露问询键，UCL 中对应的转发文本保持原样。

**问询门序（`ask_for_join/0`）**：`family/family_name != "峨嵋派"` →
`class == "bonze"` → `gender != "女性"` → `set_temp("pending/join_bonze", 1)`。
通过后 LPC 有两段不同输出：`command("say 阿弥陀佛！...请跪下(kneel)受戒。")` 是 NPC
房间发言，`return "记住，既然出了家，就一心向佛，不能还俗。"` 是私发玩家文本；
ex 用 `kind = "emei_tonsure"` + UCL `npc_say` 分别保留，拒绝分支不广播。

**`kneel` 仪式（`do_kneel/0`）**：只在对应师太房间且 NPC 身份匹配时生效；无 pending
则 LPC `return 0`，ex 返 `:not_handled` 且不播文案。成功时按原序完成：三段 vision
（玩家 `$N`、师太 `$n`）→ 取 `purename` 优先、否则 `name` 的首字 →
随机前缀 `灵/文/心/妙` 组成二字法名 → NAME_D remove/map + DB 改名 →
NPC `say 从今以后你的法名叫做<法名>。` → `nod` → `marks/old_name` →
删除 pending → `class = bonze` → `K_record = PKS + MKS` →
`shen_record = 旧 shen` → `shen = 0`。

| 静真 | `emei:fushouan` |
| 静虚 | `emei:hcaguangchang` |

共用别名「shitai」不参与 NPC 匹配，避免同房间其他师太误触发；NPC id 与唯一别名/姓名
三重校验。九个房间的 NPC id/姓名/唯一别名逐项锁在
`test/kantele/world/npc_actions_emei_kneel_test.exs`。
