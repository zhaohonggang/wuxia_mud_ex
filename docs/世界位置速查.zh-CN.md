# 世界位置速查

本文档整理了游戏中几个常见位置和物品的获取方式，所有信息均来自 `data/world/*.ucl` 世界数据文件。

> **巫师权限**：以下所有地点均可使用 `goto <房间ID>` 快速传送（仅巫师可用）。例如：`goto gumu:zhengting` 直接前往古墓正厅。  
> 要成为巫师，需在数据库中将角色的 `wiz_level` 设为 ≥1。  
> 当前角色 `grant`（id=1）已设为 **admin（`wiz_level = 3`）**，拥有全部巫师权限，可直接使用 `goto` 命令。

**位置**：`data/world/kunming.ucl` —— 昆明区域（kunming），吴三桂所在房间

**NPC**：吴三桂（`wusangui`，aliases: ["wu sangui", "wu"]，title: 平西王）
- 性别：男性，年龄：58，态度：peaceful
- 战斗经验：3,000,000，技能：unarmed/dodge/parry/sword/force 120 级，gun/hammer 120 级

**物品**：**大理石屏风**（`pingfeng`，aliases: ["ping feng", "ping", "feng"]）

## 2. 猎人的房间

**位置**：`data/world/hengyang.ucl` —— 衡阳区域（hengyang）

**房间名称**：树林（`shulin1`）

**房间坐标**：x = -3, y = -5, z = -2

**房间描述**：
> 这里是衡山半山腰的一片树林，据说这里经常有野兽出没。

**NPC**：猎人（`hunter`，aliases: ["hunter"]）
- 性别：男性，年龄：45
- 态度：peaceful（友好）
- 技能：unarmed/dodge/training/hunting 均为 300 级

**goto 命令**：`goto hengyang:shulin1`

## 3. 在哪里买捕兽夹

**物品定义**：`data/world/clone_lib.ucl`

**物品名称**：捕兽夹

**物品描述**：
> 夹齿锋利的捕兽夹，你可通过它布置 (snare) 陷阱来捕猎。

**购买地点**：各地的 **杂货铺** 可能出售捕兽夹。已知有杂货铺的城市包括：
- 北京（beijing.ucl）—— 东长安街杂货铺
- 长安（changan.ucl）—— 城南杂货铺
- 城（city.ucl）—— 南边杂货铺，老掌柜私底下也卖一些贵重东西
- 衡阳（hengyang.ucl）—— 小杂货铺
- 荆州（jingzhou.ucl）—— 北边杂货铺
- 洛阳（luoyang.ucl）—— 胡同口杂货铺，私底下也卖贵重东西

**如何获得**：在杂货铺向老板 `list` 查看商品，若有捕兽夹则可 `buy` 购买。

**用途**：
1. 使用 `snare` 命令在房间布置陷阱，捕猎野兽获得生肉。
2. 把捕兽夹交给衡阳树林的猎人，可学习捕猎技能。

## 5. 哪里有大树枝、如何生火、烤肉

### 大树枝 / 木柴

**物品定义**：`data/world/clone_lib.ucl` —— `items "wood"`

**材质**：wood

**已知出现地点**：
- 长安某房间（changan.ucl）引用了 `{ id = clone_lib.items.wood.id }`
- 白驼山柴房（baituo.ucl）—— 有 "柴"、"木柴" 物品，房间描述："这是间不宽的柴房，木柴已经快烧光了，剩余的几堆干柴乱七八糟摆放在地面，墙角放着一柄柴刀。"

### 如何生火

**命令**：`fire <木柴>` / `点火 <木柴>` / `生火 <木柴>`

**实现**：`lib/kantele/character/commands/fire_command.ex`

**原理**：
- 消耗背包中带 `fire_to` 字段的木柴
- 在所在房间地面生成一堆篝火（`clone_lib:needfire`）
- 木柴被销毁

### 如何烤肉

**命令**：`kao <物品>` / `烤 <物品>`

**实现**：`lib/kantele/character/commands/kao_command.ex`

**前提条件**：
1. 房间地面必须有 **篝火**（item_id == `clone_lib:needfire`）—— 可用 `fire` 命令生成，或在衡阳树林（shulin1）直接使用现成篝火
2. 背包中必须有 **生肉**（`meta.raw_meat == true` 且 `meta.broil_to` 非空）—— 通过 `snare` 布置陷阱捕猎获得

**效果**：消耗生肉实例，按 `broil_to` 生成熟食实例进入背包。

### 完整流程示例

1. 在杂货铺买 **捕兽夹**
2. 前往衡阳树林（shulin1）找猎人
3. 使用 `snare` 布置陷阱捕猎，获得 **生肉**
4. 背包中若无木柴，先在长安或白驼山柴房获取 **木柴**
5. 使用 `fire 木柴` 在房间生成 **篝火**（或直接使用衡阳树林现成的篝火）
6. 使用 `kao 生肉` 将生肉烤成 **熟肉**
7. 可将捕兽夹交给猎人，学习 **捕猎** 技能

## 8. 把 grant 设成巫师

**数据库操作**：
```sql
UPDATE characters SET wiz_level = 1 WHERE id = 1;
```

**效果**：`grant`（id=1）的 `wiz_level` 从 0 变为 1，即成为巫师。

**巫师权限等级**：
- `wiz_level >= 1`：巫师（可使用 `goto`、`dest`、`detail` 等巫师命令）
- `wiz_level >= 2`：arch 巫师（可使用 `clone`、`build` 等）
- `wiz_level >= 3`：admin

当前 `grant` 已设为 `wiz_level = 3`（admin），拥有全部巫师权限，可直接使用 `goto` 命令传送到上述各地点。
