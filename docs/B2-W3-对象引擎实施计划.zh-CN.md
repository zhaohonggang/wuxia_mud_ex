## 二、设计原则

1. **守门复用**：全部 6 命令继续使用 `WizArch.guard/3` + `Access.wizardp/1`（巫师即可，无需 arch 级更高门槛，除非系统操作另有规定）。
2. **不引入占位桩**：任何新命令回执不得包含 `暂未开放/暂未实现/还没实现/尚未开放/系统暂未`，保持 `command_probe_test.exs` 白名单 `%{}` 零误报。
3. **复用现有基础设施**：`ObjectClone.clone_by_path/3` 做对象实例化；`Kalevala.Character.Command.Router` DSL 做路由；`CommandView`/`render`/`prompt` 做回执。
4. **遵循 daemon 惯例**：新 GenServer 持公共 ETS，写入直接 `:ets.insert` 不经 `GenServer.call`；`ensure!/0` 补建表；`read_state/0` 表缺失返缺省。
5. **分层交付**：call/reboot/shutdown 为 MVP（本计划）；possess/restore/build 为后续（依赖更重的世界/持久化系统，预留接口，本阶段保留 `not_modeled` 回执）。

## 四、核心模块设计

### 4.1 `lib/kantele/world/w3_object_engine.ex`

```elixir
defmodule Kantele.World.W3ObjectEngine do
  @moduledoc """
  W3 对象引擎核心（GenServer，公共 ETS）。

  对应 LPC W3 对象系统的运行时注册表。提供对象实例的注册、查询、销毁与列表，
  供 call/reboot/shutdown 等 arch 命令复用。

  表 `w3_objects`：
    key   -> {:object, id}
    value -> %{module: atom, state: map, owner: binary, created_at: datetime, parent: id | nil}

  遵循 daemon 惯例（Pkd/Vote/Security/Prison）：
    - ensure!/0 补建表
    - 写入直接 :ets.insert，不经 GenServer.call
    - read_state/0 表缺失返缺省
  """

  use GenServer

  @table :w3_objects

  # --- GenServer API ---

  def start_link(opts \\ []) do
    GenServer.start_link(__MODULE__, opts, name: __MODULE__)
  end

  def init(_opts) do
    ensure!()
    {:ok, %{}}
  end

  # --- 公共操作（直接 ETS，供命令模块调用）---

  @doc "注册一个已实例化的对象引擎条目。返回 :ok 或 {:error, :already_registered}。"
  def register(id, module, state, owner \\ nil) do
    :ets.insert(@table, {{:object, id}, %{module: module, state: state, owner: owner, created_at: DateTime.utc_now(), parent: nil}})
  rescue
    _ -> {:error, :already_registered}
  end

  @doc "查询对象条目，缺失返回 nil。"
  def lookup(id) do
    :ets.lookup(@table, {:object, id}) |> case do
      [{{:object, ^id}, entry}] -> entry
      [] -> nil
    end
  end

  @doc "销毁对象条目，返回 :ok 或 {:error, :not_found}。"
  def unregister(id) do
    :ets.delete(@table, {:object, id}) |> case do
      1 -> :ok
      0 -> {:error, :not_found}
    end
  end

  @doc "列出所有对象 ID。"
  def list do
    :ets.lookup(@table, :_) |> ... # 实际用 :ets.match / :ets.select
  end

  # --- 内部 ---

  defp ensure! do
    :ets.new(@table, [:public, :named_table, :set])
  rescue
    ArgumentError -> :ok # 已存在
  end
end
```

关键设计点：
- ETS 表为 `:named_table`，供任意进程直接读写（遵循 daemon 惯例）。
- `register/4` 中 `state` 可存放对象运行时态（如 qi、位置、属性），由调用方维护。
- 与 `ObjectClone.clone_by_path/3` 配合：先经 ObjectClone 实例化，再经 `W3ObjectEngine.register/4` 登记，后续 `call` 可通过引擎查找并调用。

### 4.2 命令模块设计（6 个）

全部命令路由均使用 `optional(empty() |> spaces() |> text(:rest))`，确保裸命令与带参命令都能解析（遵循 `commands.ex` 中已有约定，如 `detail`/`remove`/`push`）。

#### 4.2.1 `call <对象> <函数> [参数...]`

文件：`lib/kantele/character/commands/call_command.ex`

- **门控**：`WizArch.guard(conn, params, &handle/2)`（巫师即可）。
- **参数解析**：`params["rest"]` 按空白拆分，第一段为对象 ID/路径，第二段为函数名，余下为参数。
- **对象查找**：
  1. 先在 `W3ObjectEngine.lookup/1` 中按 ID 查找；
  2. 未命中则经 `ObjectClone.clone_by_path/1` 按路径加载（支持 `zone:id` 和 `/clone/*.c`）。
- **调用**：`Module.apply(obj.module, func, args)`，或对象模块导出的 `func/arity`。
- **返回**：成功返回 `"调用 #{func} 结果: #{inspect(result)}\n"`；失败返回具体原因（对象不存在、函数不存在、参数类型错误等）。
- **权限**：对象注册时可标记 `owner`，调用时若 `owner != caller.name` 且非 admin，返回权限拒绝。

#### 4.2.2 `reboot [延迟秒]`

文件：`lib/kantele/character/commands/reboot_command.ex`

- **门控**：`WizArch.guard`（巫师）；建议系统级操作限 `Access.adminp/1`（级别 3），或按 LPC 习惯由 arch 执行，本阶段统一巫师即可，文案说明受限。
- **行为**：调度 `:timer.send_after(delay_ms, self(), {:reboot, conn.character.name})`，GenServer 收到后向在线角色广播重启预告，然后执行 `Application.stop(:kalevala)` / `Application.stop(:kantele)`（应用层受限，不重启 OS/容器）。
- **边界**：`delay = 0` 时立即执行；支持通过 `shutdown` 取消待处理重启（预留 `cancel` 子命令）。

#### 4.2.3 `shutdown [延迟秒]`

文件：`lib/kantele/character/commands/shutdown_command.ex`

- **门控**：同 reboot。
- **行为**：调度停机，先向在线角色广播停机预告，正常关闭连接与保存状态，再 `Application.stop(:kantele)`。
- **边界**：与 reboot 共享调度器，避免重复调度。

#### 4.2.4 possess / restore / build

文件：保持现有 `not_modeled` 回执，`moduledoc` 补充「依赖 XXX 系统，后续阶段实现」。
