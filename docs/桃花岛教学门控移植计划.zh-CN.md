### 7.1 实施中发现并修正的三个静默缺口

1. **teach_skills 数值写法**：第一版 UCL 把 `force = 180` 直接写在 `teach_skills` 中，
   `loader.parse_teach/1` 只认 `{ max = N gongxian = 0 }`，导致 7 NPC 共 105 项技能
   `max` 全被静默归零。已改为 inline map，并在测试中断言 `max > 0` 防回归。
2. **inquiry map 的 UCL 布尔/键形态**：`no_family_check = true` 到 inquiry map 是字符串
   `"true"`；`any_min_skills` 保留 atom 键。引擎已分别接受 `true`/`"true"` 并统一转换技能键，
   否则九阴四招同门门和碧海潮生三选一门都走不通。
3. **loader 默认 `min_shen: 0` 误伤**：`lpc_taohua` 原按 `shen < min_shen` 判侠义门，
   会让 feng/lu/qu 拒绝所有负神玩家（LPC 三人无侠义门）。loader 新增
   `taohua_shen_gate`（读原始 UCL 是否写了上下界），仅黄药师为真。
