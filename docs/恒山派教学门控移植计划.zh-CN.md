## 1. teach / no_teach

- `teach = { family = "衡山派" teach_skills = { ... } }`，每项 `max` 取 LPC `set_skill`
  原值、`gongxian = 0`（与既有批次一致）。
- 刘正风 `no_teach` 两项（map → loader 转 `no_teach_deny` 硬拒）：
  - `liuyun-zhang`：「这流云掌向来只由掌门人亲授，你还是找我师兄传授吧！」
  - `shilin-jian`：「石廪剑法向来只由掌门人亲授，你还是找我师兄传授吧！」
- 鲁连荣 `no_teach/zhenyue-jue`：「这门内功我也是刚练不久，生疏得紧。」
- 注意 LPC `liu.c:46` 写作 `set_skill("liuyun-zhang" , 220)`（逗号前有空格），
  解析脚本必须用 `\s*,\s*`，否则会漏掉一项（实测 22 vs 23）。

## 2. 收徒门（henshan.h + 逐 NPC）

`henshan.h permit_recruit` 三条：叛门 → `betrayer/times` → 他派。映射为
`permit_recruit = true` + `family = "衡山派"` + 三句逐字 deny。

逐 NPC 在 permit_recruit 之后的顺序均为
**shen → combat_exp → henshan-jian → force**（米为义例外：先拒 `master_id = "xiang danian"`
的向大年弟子，再 `shen >= 0`，无其它门）。

| NPC | shen | combat_exp | henshan-jian | force | 专用文案 |
| --- | ---: | ---: | ---: | ---: | --- |
| 刘正风 | 30000 | 200000 | 120 | 150 | 名门正派要求严格 / 重视剑法 / 内功为御剑之本 |
| 鲁连荣 | 5000 | 50000 | 50 | 100 | 同上 |
| 米为义 | 0 | — | — | — | 拒向大年弟子 + 「你这人不做好事，我衡山派可容你不得。」 |
| 莫大 | 40000 | 300000 | 120 | 180 | 掌门门控，逐字同刘正风 |
| 向大年 | 2000 | 20000 | 30 | 80 | 「你非侠义之辈，岂能入我衡山剑派？」等 |

- 米为义的 `master_id` 门可用引擎已有的 `reject_master_name = "xiang danian"`
  + `reject_master_name_deny`，位置紧随 permit_recruit，与 LPC 一致。
- **顺序风险**：`min_skills` 是 map，`first_failing_recruit_skill/2` 用 `Enum.find`
  遍历，Elixir map 顺序不保证；henshan-jian 与 force 的拒绝文案不同，必须新增
  `recruit_skill_order` 有序链（Task #860，缺 key 不拦，老配置零影响）。

## 3. 10 条绝招（`gate_order = "lpc_masterd"`）

**同门 → 已会 → shen → gongxian → sk1 存在/等级 → force → dodge → neili**。
引擎既有 `inquiry_grant_lpc/3` 与该顺序一致，无需新增 gate_order；
`level_order = ["<sk1>"]` 固定技能链，`min_force` / `min_dodge` / `max_neili`
对应 LPC 的 `force` / `dodge` / `neili` 三个独立键。
