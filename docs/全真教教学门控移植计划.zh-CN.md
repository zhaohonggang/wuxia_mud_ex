# 全真教（quanzhen）教学门控移植计划

> 任务：Task #619 续批（quanzhen，Task #951-#955）；按门派字母序，欧阳世家（ouyang）之后为 `quanzhen`。
> 依据：LPC `kungfu/class/quanzhen/*`（23 文件）与 `feature/{master,coagent,guarder,quester}.c`；
> ex `data/world/clone_lib.ucl`、`data/world/quanzhen.ucl`、`lib/kantele/sect_master.ex`、
> `lib/kantele/world/loader.ex`、`lib/kantele/world/inquiry_handlers/sect_master_grant.ex`。
> 原则：完整移植、零信息丢失；LPC 有而 ex 无的机制显式登记 GAP 并建 Task，严禁简化替代。

## 1. 审计结论（2026-11-22）

LPC 目录含 22 个 `.c` + `quanzhen.h`。其中 20 个 NPC 共用 `quanzhen.h permit_recruit`，
`ji.c` / `pi.c` 不引入该头文件且无条件拒收。没有任何文件定义 `teach` / `teach_pfm`，
普通授艺全部继承 `F_MASTER`；仅 `wang.c` / `zhou.c` 用 `no_teach/<skill>` 逐技能拒绝，
`zhou.c` 另有 `recognize_apprentice` 标记门。绝招全部是内联 `ask_skill*`，不经 `MASTER_D->teach_pfm`。

### 1.1 `quanzhen.h` 逐字门序

1. `detach/全真教` 或 `betrayer/全真教` → `你当年既然离开全真教，何必又要回来？`
2. `betrayer/times` → `我们全真教乃名门正派，决不收判师之徒！`
3. 已有别派且不是全真教 → `你既然已经有了名师指点，不好好学习，来我们全真教作甚？`

### 1.4 其它 LPC 机制

- `no_teach`：王重阳仅 `yiyang-zhi`；周伯通 `xiantian-gong` / `yijin-duangu` / `shexing-lifan`。
- 周伯通 `recognize_apprentice`：无 `can_learn/zuoyou-hubo/zhou` 一律「我又不是你师父，为啥要教你？」；
  有标记但技能非 `zuoyou-hubo` → 「你的武功比我还好，你教我还差不多。」
- `set_temp("apply/*")`：刘/马/丘/谭/王 100/100/200；周伯通 200/200/600。
- 战斗闲聊：每个 NPC 的 `chat_msg_combat` 数组（部分调用 LPC 招式命令）需逐字保留为台词。
- 丘处机 `coagents`：马钰（startroom `quanzhen:shiweishi`）、王处一（`quanzhen:wanwutang`）。
- 马钰 `F_COAGENT`/`F_QUESTER`；王处一 `F_COAGENT`；丘处机 `F_GUARDER` + greeting + check_body。
- 周伯通 `accept_fight` / competition_with / `lost()` 奖励与 `can_learn/zuoyou-hubo/zhou` 链。

## 2. 引擎改动（nil-safe，老配置零影响）

1. `sect_master.ex`：`inquiry_grant/3` 新增 `gate_order = "lpc_quanzhen"` → `inquiry_grant_quanzhen/3`。
   顺序：perform nil → maxed → family → skill 存在 → gongxian → shen → `level_order` → `requires_perform`。
2. `sect_master.ex`：`recruit_gate?/3` 新增 `gate_order = "lpc_quanzhen"` → `quanzhen_recruit_gate/6`，
   用 `recruit_profile` 区分 simple / junior_shen / junior_neigong / neigong_taoism / ma / qiu / sun / wang / zhou。
   内功 OR 门复用 `any_min_skills`，其余 AND 门复用 `min_skills`。
3. `sect_master.ex`：`teachable?/1` 的 unlock 支持 `only_skill` / `only_skill_deny`（周伯通 recognize_apprentice）。
4. `loader.ex`：apprentice gate_order 白名单加 `lpc_quanzhen`；`parse_teach/normalize_unlock` 解析
   `only_skill` / `only_skill_deny`；其余字段（recruit_profile/any_min_skills/hard_min_int/deny_all）复用既有解析。
