## 2. 本批实现（Task #799）

### 2.1 `back` / `离岛` → `teleport_service` 扩展

LPC `ask_back`（long.c:105-126 / mu.c:109-130）为经验上界门控：

- `combat_exp >= 100000` → 只播 `message_vision`，无私聊、不移动（龙：「你没长腿？」／木：「你不自己走么？」）。
- 否则播岛主让李四/张三送客的 vision → `me->move("/d/xiakedao/haitan")` → 目标房间再播陪同 vision → `tell_object` 两句私聊。

`Kantele.World.InquiryHandlers.TeleportService` 新增可选字段：

- `max_exp` / `max_exp_vision`：优先于 family / startroom 判定；`{name}` 入队前替换为问者名，`{npc}` 由 VisionView 按接收者渲染。
- `target_vision`：传送后在目标房间广播，同样支持 `{name}`。

旧配置不写这三个字段即保持原行为（平四传送链零回归）。龙岛主/木岛主的
`back` 与 `离岛` 两个键都落同一套配置，目标房间 `xiakedao:haitan`。

### 2.2 石破天 `attempt_apprentice` 无条件拒绝

LPC `shi.c:105-109` 只有 `command("ah")` + `command("say 那不成...")`，没有任何收徒分支。
UCL 新增：

```ucl
apprentice = {
  deny_all = true
  deny_msg = "石破天说道：那不成，那不成。我自己都还没学好呢。"
}
```

- `loader.parse_apprentice/1` 透传 `deny_all` / `deny_msg`。
- `Kantele.Character.NpcFamilyEvent.apprentice/2` 在 `teach.family` 应允路径之前
  检查 `deny_all`，直接回 `%Event{topic: "family/result", data: %{ok: false, ...}}`。
- `deny_all` 缺省 false，老 NPC 零影响。

### 2.3 文本问询与 GAP 标记

- 龙/木 `腊八粥` 落 LPC 原文（去色彩码），但私有 tell ≠ LPC `message_sort` 房间广播，见 #803。
- 石破天 8 键逐字落库（石中玉/阿绣/谢烟客/狗杂种/侠客岛/史婆婆/太玄功/太玄神功）。
- 张三「赏善罚恶令」原值是裸闭包字符串 `"(: give_ling :)"`，改为明确
  `unimplemented: GAP #800`，禁止把闭包字符串当玩家可见文案。
- 黄衣使者 `rent`/`同门`/`师兄` 全部改为 `unimplemented: GAP #801`。

## 4. #802 岛主 greeting exp 分级实现

- `lib/kantele/world/npc_greeting.ex` 的块 id 别名注册表新增
  `"xiakedao_long"` / `"xiakedao_mu"`，解决 clone_lib NPC 运行期 hash id
  无法按 `"zone:name"` 命中的问题（沿用 #758 的别名派发模式）。
- 新增 `XiakedaoLong` / `XiakedaoMu` / `XiakedaoDaozhu` 三个处理器模块。共用门序
  严格照抄 LPC：`interactive(this_player())` → `!is_fighting()` → `random(3) == 1`
  → `combat_exp < 10000`（低档文案）→ `< 100000`（高档文案）→ 沉默。
  两个阈值均取严格小于；`10000` 走高档，`100000` 完全沉默。
- 文案逐字保留 LPC 标点，包括低档句末的 `”`（与高档的 `“` 不同），未做「规范化」。
- 近似：LPC 的 `call_out("greeting", 1, ob)` 1 拍延迟 + 到期同房复查，改为进屋当拍
  同步广播（入住即视为仍在同房），与 #758 何足道 greeting 的既有可接受近似同类。
- `data/world/clone_lib.ucl` 的两条静态 `greetings` 保留为未注册命中时的兜底池；
  注册命中后不再随机取池，避免高经验玩家听到低档台词。
- 测试：`test/kantele/world/npc_greeting_test.exs` 新增 9 用例，覆盖两名岛主、
  10,000/100,000 双边界、战斗中沉默、1/3 概率门、别名派发与进屋广播。

## 5. #803 `message_sort` 问询广播实现

- 新增 `lib/kantele/world/inquiry_handlers/message_sort.ex` 并在
  `InquiryHandlers` 注册 `kind = "message_sort"`。纯数据驱动，不改变其他 inquiry。
- 按 `adm/single/simul_efun/message.c:58-92` 的三视角渲染：问询玩家收到
  `$N`→NPC 名、`$n`→「你」的私有 vision；同房间其他人收到 `$n`→问询者名的
  房间广播（`exclude_actor: true` 防止问询玩家收到第二份）；说话人岛主无显示端，
  省略其自视角文案。同时支持 `{npc}`/`{name}` 归一化占位。
- `data/world/clone_lib.ucl` 龙/木岛主 `腊八粥` 从纯字符串改为
  `{ kind = "message_sort" text = "$N对$n说：“……”" }`，正文逐字保留
  「断肠独骨腐心草」整段。其他 NPC 腊八粥文本问询未动。
- `test/kantele/world/inquiry_handlers_message_sort_test.exs` 新增 7 用例：
  问者/旁观者两版渲染、`exclude_actor`、归一化占位、无房间 id、非问询者、
  缺配置、两名岛主 UCL 落位；旧 `inquiry_sect_masters_test.exs:2051` 断言同步更新。
