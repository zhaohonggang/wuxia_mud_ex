## 0. 一句话总览

```
连线 → 取英文 ID → 确认新建 → 设密码 → 选性别(m/f)
  → 进入世界，直接落在「阎罗殿」(BORN_ROOM)
  → washto <膂力 悟性 根骨 身法>  洗点（分配先天属性，和须=80）
  → born <出生地>                 投胎（玩家自选落点，含世家姓氏）
  → 落到出生地房间，获「与生俱来」特技，阅读新手帮助
```

你记得的没错：**先进入世界 → 在阎罗殿洗点设属性 → 最后由玩家自己决定投胎到哪个地点。**

## 1. 阶段一：连线与注册账号（`logind.c` `logon`→`get_id`→`get_passwd`）

玩家用客户端连上 MUD，先看到欢迎横幅（`WELCOME` + 在线人数统计），随后系统问第一个问题：

```
您的英文名字(新玩家可以选择一喜欢的名字)：
```
- **玩家输入**：一个英文 ID（如 `zhangsan`）。
- 系统 `get_id` 校验合法性（`check_legal_id`）；非法则重复询问。
- 若该 ID **没有存档** → 询问是否新建：
  ```
  使用[zhangsan]这个名字将会创造一个新的人物，您确定吗(是请输入y，否请输入n)？
  ```
  - 输 `y` → 进入设密码；输 `n` → 重新取 ID。
- 若该 ID **已有存档**（老玩家重连）→ 直接问密码：
  ```
  请输入密码：
  ```

设密码（`get_passwd`）：
```
请设定您的密码：        （新玩家首次）
请输入您的密码：        （老玩家）
```
- 首次登录且无管理密码时，还会顺带要求设一个**管理密码**（用于密码丢失时找回）。
- 密码通过后调用 `check_ok(ob)`。

> 此阶段只是**账号层**（用户名/密码），与角色属性、性别无关。网页注册在 Ex 端口径中与之对应。

---

## 2. 阶段二：选择性别（`logind.c` `get_gender`）

账号就绪后，系统立刻问性别：

```
您要扮演男性(m)的角色或女性(f)的角色？
```
- **玩家输入**：`m` 或 `f`。
- 系统写入临时值：`set_temp("gender", "男性"/"女性")`。
- 随后立刻 `make_body` 创建角色体、`init_new_player` 初始化（称号「普通百姓」、潜力 99、初始食物/饮水、频道、环境参数等），并**临时**写入先天属性初值：
  ```
  str=14, dex=14, con=14, int=14, per=20
  ```
  > ⚠️ 这只是占位初值。**真正的属性分配不在这一步**，而在进入世界后的阎罗殿。详见阶段四。
- 最后调用 `enter_world(ob, user)` 把角色送进游戏世界。

---

## 3. 阶段三：落入「阎罗殿」（`logind.c` `enter_world` → `BORN_ROOM`）

`enter_world` 决定出生房间，优先级如下（logind.c:901-913）：

| 条件 | 落入房间 |
|---|---|
| 无 `character` 且 `age >= 16` | `REGISTER_ROOM`（`/d/register/entry`，用于「16 岁后再选天性」） |
| **无 `born`（新玩家，`age=14`）** | **`BORN_ROOM` = `/d/register/yanluodian`（阎罗殿）** ✅ |
| 其它 / 房间不存在 | `START_ROOM`（`/d/city/kedian`，兜底） |

新玩家 `age=14` 且尚未 `born` → **直接落在阎罗殿**。系统先打印：

```
你连线进入<MUD名>。
```

随后角色被 `move` 进阎罗殿，玩家看到房间描述（**阎罗殿**，阴森恐怖，两旁牛头马面，地藏王坐于大堂，角落有忘忧池，旁边一块**牌子(paizi)**）：

```
投胎乃人生大事，切记不可草率！
选好先天属性(指令：washto)之后再投胎(指令：born <中文地名>)吧。

 1. 扬州人氏
 2. 欧阳世家
 3. 关外胡家
 4. 中原苗家
 5. 段氏皇族
 6. 慕容世家
```

> 这一步相当于 LPC 的「出生地预选单」。玩家此刻**尚未投胎**，只是站在地府里准备洗点与投胎。

---

## 4. 阶段四：洗点 —— 分配先天属性（`yanluodian.c` `do_wash` / `washto`）

玩家在阎罗殿输入 `washto` 指令分配四项先天属性：

```
washto <膂力 str> <悟性 int> <根骨 con> <身法 dex>
例如：washto 20 20 20 20
```

系统校验（`yanluodian.c:112-129`）：
- 每项必须在 **10–30** 之间；
- **四项总和必须正好 = 80**，否则报错：
  ```
  你所选择的属性总和必须为80。
  ```
- 通过则写入 `str/int/con/dex`，并**随机**生成两项玩家不可自选的属性：
  ```
  per（洞察）  = 5 + random(26)   → 5~30
  kar（福缘）  = 5 + random(26)   → 5~30
  ```
- 系统反馈：
  ```
  你跳入忘忧池，顿时被一股激流卷了进去。
  只听“啪”的一声，你被湿漉漉的抛了出来。

  你这次获得的四项先天天赋分别是：
  膂力：【 20 】 悟性：【 20 】 根骨：【 20 】 身法：【 20 】
  如果你满意，就去投胎(born)吧！方法如<born 扬州人氏>
  ```
- 置临时标记 `washed=1`（未洗点者不允许投胎）。

> 玩家可**反复 `washto`** 直到满意（每次覆盖上一次）。这就是 LPC 的「总点数池 = 80」机制——并非固定 14/14/14/14/20。

---

## 5. 阶段五：投胎 —— 玩家自选出生地（`yanluodian.c` `do_born` / `born`）

洗点完成后，玩家用 `born` 指令**自己决定落到哪里**：

```
born <中文地名>
例如：born 扬州人氏
       born 欧阳世家 欧阳锋      （世家可附带自定义名字）
```

系统校验：
- 若未洗点（`!washed` 且非转世）→ 拒绝：
  ```
  你先在忘忧池中洗一下(washto)，选择好天赋你再投胎也不迟啊！
  ```
- 地名必须来自上面的 `born` 映射表，否则牛头喝问「你要干什么！投胎去哪里？」

**可选出生地清单**（yanluodian.c `born` 映射）：

| 输入 | 类型 | 落地房间 (startroom) | 附加效果 |
|---|---|---|---|
| `扬州人氏` | 普通地域 | `/d/city/kedian`（扬州客店） | 无姓氏 |
| `欧阳世家` | 世家 | `/d/baituo/dating` | 强制姓氏「欧阳」 |
| `关外胡家` | 世家 | `/d/guanwai/xiaowu` | 强制姓氏「胡」 |
| `中原苗家` | 世家 | `/d/zhongzhou/miaojia_houting` | 强制姓氏「苗」 |
| `段氏皇族` | 世家 | `/d/dali/wangfugate` | 强制姓氏「段」 |
| `慕容世家` | 世家 | `/d/yanziwu/cuixia` | 强制姓氏「慕容」 |

- 普通地域：直接设 `startroom` + `born` + `born_family="没有"`。
- 世家：额外设 `surname`（强制姓），若玩家在 `born` 后附了名字则套用「姓氏+名」；并把玩家归入对应家族。
- 随后：
  ```
  mud_age = 0
  age = 14
  registered = 1
  save()
  ```

> **关键点**：投胎落点完全由玩家在 `born` 时决定；不同地域/世家对应不同的初始房间与姓氏，这是 LPC 出生地多样性的来源。

---

## 6. 阶段六：落地出生地 + 获得「与生俱来」特技（`updated.c` `born_player`）

投胎成功后，系统把角色 `move` 到所选 `startroom`，并执行 **`UPDATE_D->born_player(me)`**（仅非转世者），随机赠予 1–3 项**与生俱来的特殊技能**（`updated.c:344-445`）：

- 从 `special_skill/*` 池中排除转世/特殊技（guibian、guimai、jinshen、piyi、lighting、qinzong、wuxing、shenyan、tiandao、herb、wrach、trick 等）；
- 按 **`character`**（新玩家恒 nil → 恒排除 `wrath`/`trick`）与**先天属性 ≥20** 过滤（如 `str<20` 排除 `strength`，`int<20` 排除 `intellect`/`clever`，`con<20` 排除 `constitution`，`dex<20` 排除 `dexterity`，`per<20` 排除 `youth`）；
- 随机抽 1–3 项写入 `special_skill/`；若抽中 `strength/intellect/constitution/dexterity` 再 **+2** 对应属性；
- 系统提示（示例）：
  ```
  你与生俱来的技能有：麒麟血臂、罡睿神慧。
  如果你对此有任何疑问，可以重新阅读天赋属性(help gift)介绍。
  ```

最后：
```
牛头飞起一脚，将你踢了出去。
$N揉揉眼睛，迷惘的望着这个陌生的世界。
```
并自动打开新手帮助：
```
（显示 help topics 新手主题列表）
```

至此，**新用户注册全流程结束**，玩家正式开始于所选出生地。

## 7. 关键规则速查

| 项目 | LPC 规则 |
|---|---|
| 账号问答 | 英文 ID → 确认新建(y/n) → 密码 →（可选）管理密码 |
| 性别 | `m`/`f` → 男性/女性，注册时一次性选定 |
| 临时属性初值 | str=dex=con=int=14, per=20（仅占位，**非最终值**） |
| 洗点指令 | `washto <str> <int> <con> <dex>`，各 10–30，**和=80** |
| 随机属性 | `per`、`kar` 各 `5+random(26)`（5~30，玩家不可控） |
| 投胎指令 | `born <地名>`，须先于 washto 完成 |
| 出生地选项 | 扬州人氏 + 5 世家（欧阳/胡/苗/段/慕容），世家强制姓氏 |
| 落地后 | age=14、registered=1、随机 1–3 项与生俱来特技、新手帮助 |
| 首落房间 | 阎罗殿（BORN_ROOM），洗点投胎后才进真正出生地 |

## 8. 附注：与转世的关系

- 本流程是**新玩家首次注册**。转世（`reborn`）走的是另一条线：角色死亡后到地府，经地藏王四前置（大宗师+十八层地狱+十二重天+击败地藏王）→ 六道轮回 → `zhuan_player`，转世后 `reborn=1`，投胎时**可跳过洗点直接 born**，且 `character` 被设为「国士无双」。详见分析文档 §3 与迁移计划 §3。
- 新玩家 `character` 恒为 `nil`（无任何设定入口），与转世形成对照。
