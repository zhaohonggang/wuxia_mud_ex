### 1.1 必须修复的方向性偏差

1. **permit 文案全错**：`honghua.h` 三句分别为「我们红花会四大戒条你还记得吗？亏你还有脸回来！」
   「哼，阁下不忠不信，我们红花会可不会收留。」「阁下既有了师承，还来我们红花会做什么？」；
   缺省是少林味，必须逐 NPC 覆写。
2. **陈家洛内力门顺序错**：LPC 是 exp → 红花心法 → max_neili；缺省把 max_neili 放最前，
   两门同时失败时文案与 LPC 相反。
3. **grant 已会门必须在同门前**：所有 `ask_skill*` 先判 `can_perform/<id>` 再判同门；
   `lpc_masterd` 正好相反，不能用。
4. **技能存在门必须在贡献前**：LPC 先 `query_skill(<本招>,1) < 1`，再 `gongxian`；
   缺省/default 的同门后直接贡献会漏掉这一门。
5. **等级文案逐条独立**：force / dodge / max_neili / 本招等级各有一句 LPC 原文，
   旧 UCL 合用一条 `level_deny` 会丢失信息，必须用 `level_order` + `level_deny` map。
6. **`剑盾珠索`/`白龙剑`/`芙蓉金针`/`回龙璧` 是物品发放**，不是绝招；
   旧 `剑盾珠索` grant 连 perform_id 都写成了不存在的 `jiandun-zhusuo/suo`。

## 2. 门序与门型（LPC 原序，不得合并/重排）

### 2.1 `honghua.h permit_recruit`（9/11 clone_lib NPC 调用）

1. `detach/红花会` 或 `betrayer/红花会` → 「我们红花会四大戒条你还记得吗？亏你还有脸回来！」
2. `betrayer/times` → 「哼，阁下不忠不信，我们红花会可不会收留。」
3. 已有他派 `family_name` → 「阁下既有了师承，还来我们红花会做什么？」

陆菲青不 include `honghua.h`、石双英 include 但不调用；两者走无条件拒绝。
余鱼同先调用 permit，再无条件拒绝，单列 `lpc_honghua_yu`。

### 2.2 收徒门序

| NPC | 门序（LPC 原文） |
| --- | --- |
| 常赫志/常伯志 | permit → shen≥5000 → honghua-xinfa≥50 |
| 陈家洛 | permit → shen≥65000 → exp≥400000 → honghua-xinfa≥100 → max_neili≥2000 |
| 蒋四根/骆冰/杨成协 | permit → shen≥-1000 |
| 文泰来 | permit → shen≥10000 → exp≥150000 → honghua-xinfa≥60 |
| 赵半山 | permit → shen≥15000 → exp≥200000 → honghua-xinfa≥80 |
| 无尘道长 | permit → shen≥20000 → exp≥350000 → honghua-xinfa≥80 → sword≥80 |
| 陆菲青/石双英/余鱼同 | 无条件拒绝（余鱼同先 permit） |

除陈家洛、余鱼同外均可由缺省 `permit_first` + 逐字 deny/accept 精确表达；
无尘道长须写 `recruit_skill_order = ["honghua_xinfa", "sword"]` 固定两门顺序。

### 2.3 16 条内联 `ask_skill*` 问询链

统一门序（`gate_order = "lpc_honghua"`）：

1. `can_perform/<perform_id>` 已会 → `maxed`
2. 门派不符 → `family_deny`（陆菲青三条同时接受 红花会/武当派，武当派另有一句专属拒绝）
3. `query_skill(<本招>,1) < 1` → `skill_deny`
4. `gongxian < N` → `gongxian_deny`
5. `shen < N` → `shen_deny`
6. 前置绝招（仅无尘 `诛天刹神`）→ `requires_perform_deny`
7. `level_order` 指定的有序门槛 → 各自 `level_deny`：
   `dex` / `max-neili` / `force` / `dodge` / 本招技能，顺序严格照 LPC

`lpc_masterd` 不能用（同门在已会前）；缺省路径不能用（贡献先于技能存在、
等级链无序、max_neili 落在等级之后）。
