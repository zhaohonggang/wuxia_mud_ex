### 2.1 技能 id 陷阱：`songshan-sword` 是转换器产物

- 嵩山剑法在 ex 同时存在两个技能模块：`songshan-jian`（真实 LPC `songshan-jian.c`，**带 perform `songshan-jian/meng`「如梦如幻」**）与 `songshan-sword`（`translate_skill.exs` 生成的 `songshan-sword.c`）。
- 转换器把 NPC 技能槽填成 `songshan-sword`（mapped type `sword`），**但这只是战斗映射别名**；真正可作 `sk1`/学习/绝招门槛的是 `songshan-jian`。
- 故 `teach_skills` / `min_levels` / `sk1` 一律用 `songshan-jian`（下划线书写 `songshan_jian`）；`songshan-sword` 仅在需要与既有 `skills` 映射对齐时保留原样。
- 左冷禅内功：LPC `map_skill("force","hanbing-zhenqi")`（寒冰真气）。ex `skills` 用 `songshan-xinfa`（converter 的近似），**不擅改战斗数据**；`teach_skills` 同时列 `songshan_xinfa` 与 `hanbing_zhenqi`（两者 set_skill 均为 280），收徒内功名按 LPC 判 `songshan-xinfa`（见 §3.4）。

## 4. 绝招授受（13 条 sect_master_grant）

门控权威 `masterd.c teach_pfm`（第 52-266 行）固定顺序：
① `perform` / `name` 缺失 → 0 → ② `free` 未设时 **同门**（`family_name !=` → `X与我<family>素无渊源，不知此话从何说起。`）→ ③ **已学会**（随机 4 句，取第 4 句 `这招你不是已经会了么，还缠着我做甚？`）→ ④ **神**（`shen<0` 要求 `shen>shen` 拒；`shen>0` 要求 `shen<shen` 拒）→ ⑤ **贡献** `gongxian<` 拒 → ⑥ temp1..3 → ⑦ **sk1 存在/等级** → ⑧ sk2..sk5 → ⑨ **force** → ⑩ **dodge** → ⑪ neili / jingli → 通过（教 perform + `improve_skill(sk1,1500000)` + 扣 gongxian）。

### 4.1 引擎适配决策：复用 `gate_order = "lpc_masterd"`（零引擎改动）

**审计结论（2026-11-21 复核）**：嵩山 4 招与 **衡山派**（同为五岳剑派）完全同构 ——
衡山派早已用 `gate_order = "lpc_masterd"`（`inquiry_grant_lpc`，sect_master.ex:727-788）
+ 逐字 masterd.c 缺省文案覆写落地（clone_lib.ucl:18952+ 乱剑覆花块）。嵩山 `songshan.h`
的 `permit_recruit` 三条与衡山 `henshan.h` **逐字相同**（仅门派名不同），
`masterd.c teach_pfm` 又是全服共用的授艺守护进程。因此：

- **直接复用 `lpc_masterd` 分支，无需新增 `lpc_songshan` 分支、无需任何引擎/loader 改动**。
- 收徒门（max_shen/min_shen/min_exp/recruit_skill_order/permit_recruit）loader `parse_apprentice` 已全支持。
- 残阳剑 give_item 走 `kind = "give_item"`（GiveItem handler 已支持全部字段）。

`inquiry_grant_lpc` 门控顺序（sect_master.ex:739-787）与 masterd.c `teach_pfm` 逐条对应：
同门(family) → 已会(maxed) → 神(max_shen 负 / min_shen 正) → 贡献(gongxian) →
技能存在(skill_deny) → 技能等级(first_failing_lpc_level/level_order + meets_levels/level_deny_text) →
force(min_force/force_deny) → dodge(min_dodge/dodge_deny) → neili(min_max_neili/max_neili_deny) →
通过。**与 masterd.c 第 76-211 行原顺序一字不差**。

Songshan 13 招的 `force` / `dodge` 门槛走 `force_deny` / `dodge_deny`（缺省即 masterd.c 原文）：
`你目前的内功火候不足，下去练练再来吧。` / `你目前的轻功火候不足，下去练练再来吧。`
`min_levels` 只放 `sk1`（走 skill_deny / level_deny_text），`force`/`dodge` 用专用
`min_force`/`min_dodge` 键（不进 min_levels，避免文案互换；loader 归一后直接命中）。
