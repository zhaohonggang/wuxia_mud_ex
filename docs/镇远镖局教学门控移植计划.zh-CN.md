### 2.5 王维扬 accept_object（信件 → 天刀八势）

LPC `accept_object`：仅收**引荐信**（`clone_lib:sjmletter`）与**厚背紫金刀**
（`clone_lib:houbeidao`），其余物品拒收并返回 0。#834 已按原三分支落地：
- 引荐信：已会「天刀八势」→ `shake` + `shit`；未会 → `nod → haha → say →
  message_sort(me=玩家, you=王维扬) → haha → tell_object` + 19 次
  `improve_skill(...,1500000)` + `set can_perform/bagua-dao/tian`（**不扣贡献**，
  与 ask_skill6 的 -2400 区分）。
- 厚背紫金刀：嫡传「很好，很好！」/ 非嫡传「多谢这位<respect>将厚背紫金刀交回。」+
  `destruct`。
- 其余：`你给我这种东西干什么？` + `return 0`（拒收）。

`message_sort` 此处 `me = 玩家`、`you = NPC`，与 #803 侠客岛方向相反，故专用模块
`ZhenyuanWangweiyangAccept` 自带反向渲染（玩家私有版 `$N`→「你」、`$n`→王维扬；
旁观版 `$N`→玩家名）。emote 文案取自 LPC `/data/emoted.o` 原定义。
另有 `engage = { fight = { accept = false } }`（LPC `accept_fight` 返回 0）。
