## 2. `teach` / `no_teach` 回填

统一 wrapper（loader `parse_teach/1` 只认 character 级 `:teach`）：

```ucl
teach = {
  family = "灵鹫宫"
  teach_skills = {
    force = { max = 120 gongxian = 0 }
    lingjiu-xinfa = { max = 120 gongxian = 0 }
    ...
  }
}
```

每 NPC 的 `teach_skills` 取该块现有 `skills` 中全部 `{ skill = ... level = ... }`，值即 LPC `set_skill` 的教学上限；`{ type = ... skill = ... }` 映射不重复写入。

xuzhu 增加：

```ucl
no_teach = {
  shaolin-xinfa = "…这…这东西我都没学好。"
  xiaowuxiang = "唉……这是师尊注如我体内的，教我怎么教给你？"
  beiming-shengong = "唉……这是师尊注如我体内的，教我怎么教给你？"
  shaolin-shenfa = "…这个…嗯…我还是教你本门的轻功好了。"
}
```

loader 已把 map 形态落为 `no_teach_deny`，但 `skills_event.teach/2` 尚未消费；见共享缺口 #742，本批保留 UCL 字段，不消费端亦可。
