# 少林派加入与剃度指南

本文档详细记录少林派（Shaolin Sect）在 LPC 源码 `kungfu/class/shaolin/*.c` 中的完整加入与剃度（出家）机制，并与 UCL 配置进行对比。数据来源于 LPC 源码，适用于新手玩家了解如何一步步成为少林派正式弟子。

> **核心特色**：少林派实行 **俗家弟子 → 剃度出家 → 正式弟子** 的三阶段入门流程，其中「剃度」是成为出家弟子（`class = "bonze"`）的必要仪式，仅有少数 NPC（清法比丘）办理。

---

## 1. 入门总览（三阶段）

| 阶段 | 身份 | 办理 NPC | 关键动作 | 说明 |
|------|------|----------|----------|------|
| 第一阶段 | 俗家弟子 | 清无、清为、清法三僧（广场） | `apprentice` 拜师 | 男性可直接拜师，学入门少林功夫，`class` 保持不变（非 bonze） |
| 第二阶段 | 出家人（剃度） | 清法比丘（广场/山门） | 询问"剃度/出家" → `kneel` 受戒 | 剃发、改名（虚/空/明/净 + 姓氏首字）、`class = "bonze"`、`shen = 0` |
| 第三阶段 | 正式少林弟子 | 各字辈长老（寺内练武场等） | 推荐信 + 斗武 → 改名字辈 | 辈分制（玄/澄/慧/道/清/渡），需已是出家人 |

> 俗家弟子**不得入寺修行**（山门守卫拦截），必须先完成剃度成为出家人，方可进入寺内拜入长老为师。

---

## 2. 第一阶段：成为俗家弟子

### 2.1 清无比丘 (`kungfu/class/shaolin/qing-wu.c`)

- 位置：少林寺前广场（`guangchang1.c` 等）
- 辈分：40（清字辈），职称：弟子
- `class = "bonze"`（NPC 自身是出家人，但收俗家弟子）

**`attempt_apprentice` 检查项**：
1. 性别必须为男性，否则拒绝（「女施主呀，贫僧可不敢开这等玩笑啊」）
2. `permit_recruit(ob)` 基础门控
3. 若 `class != "bonze"`：说「贫僧就收下你做『俗家弟子』了」
4. 执行 `recruit` 收徒

> 清无仅收男性俗家弟子，不收女性、不收无性（太监）。

### 2.2 清为比丘 (`kungfu/class/shaolin/qing-wei.c`)

- 位置：少林寺前广场
- 辈分：40（清字辈）

**`attempt_apprentice` 检查项**：与清无基本相同，区别：
1. 性别必须为男性
2. `permit_recruit(ob)` 基础门控
3. 若 `class != "bonze"`：说「贫僧就收下你做『俗家弟子』了」
4. 执行 `recruit` 收徒

### 2.3 清法比丘 (`kungfu/class/shaolin/qing-fa.c`)

- 位置：少林寺前广场（`guangchang1.c` 固定加载）
- 辈分：40（清字辈）
- 特殊：同时负责「剃度/出家」仪式

**`inquiry` 块**：
| 关键词 | 处理函数 |
|--------|----------|
| `剃度` | `ask_for_join()` |
| `出家` | `ask_for_join()` |

**`ask_for_join()` 流程**：
1. 若玩家已是 `class == "bonze"`：拒绝（「你我同是出家人，何故跟贫僧开这等玩笑？」）
2. 若性别为无性：拒绝（「这位公公，你还是回去伺候皇上吧」）
3. 若性别为女性：拒绝并指引去后山庵受戒（「女施主若真心皈依我佛，可去后山庵里受戒」）
4. 否则：设置 `me->set_temp("pending/join_bonze", 1)`，提示「请跪下(kneel)受戒」

**`do_kneel()` 剃度仪式**（执行 `kneel` 命令触发）：
1. 检查 `pending/join_bonze` 标记
2. 场景描述：NPC 将玩家头发尽数剃去
3. 改名：`prename[random] + name[0..0]`，`prename = { "虚", "空", "明", "净" }`（例如「虚XX」「空XX」）
4. `me->set("class", "bonze")` —— **正式成为出家人**
5. `me->set("shen", 0)` —— 侠义值归零
6. 记录 `K_record`、`shen_record`
7. 删除 `pending/join_bonze` 标记

> 剃度后，玩家的法名会变为「虚/空/明/净」开头，成为少林派出家弟子，方可进入寺内。

**`attempt_apprentice`**（清法也可直接收徒）：
1. 性别不能是女性
2. 性别不能是无性
3. 若 `class != "bonze"`：说「贫僧就收下你做『俗家弟子』了」
4. 执行 `recruit` 收徒

## 3. 第二阶段：剃度出家（核心机制）

这是少林派与其他门派最大的区别——必须经过剃度仪式才能成为出家弟子。

### 3.1 剃度 NPC

| NPC | 文件 | 位置 | 功能 |
|-----|------|------|------|
| 清法比丘 | `kungfu/class/shaolin/qing-fa.c` | 少林寺前广场 (`guangchang1.c`) | 询问"剃度/出家"，执行 `kneel` 受戒 |

### 3.2 剃度条件

| 条件 | 说明 |
|------|------|
| 性别 | 必须为男性（女性需去后山庵受戒，LPC 中未建模该入口） |
| 非无性 | 无性（太监）不可剃度 |
| 未出家 | `class != "bonze"`，已出家者不可重复剃度 |
| 动作 | 玩家需手动执行 `kneel` 命令 |

### 3.3 剃度效果

| 项目 | 剃度前 | 剃度后 |
|------|--------|--------|
| `class` | 玩家原职业（通常无） | `bonze`（出家人） |
| `shen` | 原有值 | `0`（归零） |
| 姓名 | 原名 | `虚/空/明/净` + 原名首字 |
| 身份 | 俗家弟子 | 少林派出家弟子 |

### 3.4 山门守卫（进入寺内的门控）

文件：`kungfu/d/shaolin/guangchang1.c`（广场大门）

`valid_leave` 检查（向北进入寺内）：
- 若玩家 `family/family_name == "少林派"`：
  - 必须 `class == "bonze"`，否则「对不起，俗家弟子不得入寺修行」
  - 需 `guilty == 0` 且 `combat/K_record == combat/WPK`，否则送去戒律院
- 若非少林派：
  - 女性：拒绝（「本寺从不接待女客」）
  - 男性且 `shen >= 0`：拒绝（「本寺不接待俗人」）
  - 其他：攻击（「邪魔外道，还不给我滚开！」）
- 持 `yingxiong ling`（英雄令）的贵客可直接入寺

> 剃度成为 `class = "bonze"` 后，方可通过山门进入寺内。

## 4. 第三阶段：正式少林弟子（辈分制）

进入寺内后，玩家可拜入各字辈长老为师，成为正式的少林派弟子。少林派实行严格的辈分制。

### 4.1 各字辈 NPC 对照表

| 辈分 | 字辈 | 代表 NPC | 文件 | 功能 |
|------|------|----------|------|------|
| 1 | 渡 | 达摩老祖 | `da-mo.c` | 开山祖师，最高门槛收徒 |
| 36 | 玄 | 玄难大师等 | `xuan-nan.c` 等 | 老辈长老 |
| 37 | 澄 | 澄字辈僧人 14 位 | `cheng-*.c` | 收慧字辈徒弟 |
| 38 | 慧 | 慧字辈僧人 10 位 | `hui-*.c` | 练武场授徒 |
| 39 | 道 | 道字辈僧人 9 位 | `dao-*.c` | 收清字辈徒弟 |
| 40 | 清 | 清无、清为、清法 | `qing-wu.c` / `qing-wei.c` / `qing-fa.c` | 收俗家弟子、办理剃度 |

### 4.2 推荐信 + 斗武晋升机制

以清字辈（辈分40）为例，`qing.h` 共享 `attempt_apprentice` 逻辑：

| 检查项 | 说明 |
|--------|------|
| `permit_recruit(ob)` | 基础门控 |
| `family_name == "少林派"` | 必须已是少林派弟子 |
| `class == "bonze"` | 必须是出家人 |
| `ob_fam["generation"] == 0` | 直接收为新入门弟子 |
| `ob_fam["generation"] <= my_fam["generation"]` | 拒绝（辈分不够） |
| `ob_fam["generation"] == my_fam["generation"] + 1` | 直接收（同门师辈徒弟） |
| `ob_fam["generation"] == my_fam["generation"] + 2` | 需持推荐信 (`apprentice_ok`)，改名为对应字辈 |

**推荐信 + 斗武流程**：
1. 持 `damo ling`（达摩令）且辈分符合 → NPC 设 `fight_ok`
2. 与 NPC **斗武**，NPC 气血降至 50% 以下 → 胜利，获得推荐信（如 `tuijian xin1`）
3. 将推荐信交给 NPC → 设 `apprentice_ok`
4. `attempt_apprentice` 检查通过 → 收徒，改名为对应字辈（如「清XX」）

> 斗武胜利条件：将 NPC 打至气血比例 ≤ 50%。

### 4.3 改名规则（辈分晋升）

| 当前辈分 | 目标辈分 | 改名前缀 | 示例 |
|----------|----------|----------|------|
| 0（新入门） | 清字辈（40） | 清 | 清XX |
| 清字辈（40） | 道字辈（39） | 道 | 道XX |
| 道字辈（39） | 慧字辈（38） | 慧 | 慧XX |
| 慧字辈（38） | 澄字辈（37） | 澄 | 澄XX |
| 澄字辈（37） | 玄字辈（36） | 玄 | 玄XX |

改名使用 `NAME_D->remove_name()` + `NAME_D->map_name()` 更新姓名。

## 5. 第四阶段：达摩祖师（最高门槛）

### 5.1 达摩老祖 (`kungfu/class/shaolin/da-mo.c`)

- 辈分：1（开山祖师）
- 职位：少林开山祖师
- `class = "bonze"`

**`attempt_apprentice` 完整检查项（按顺序）**：

| 序号 | 检查项 | 阈值 | 失败提示 |
|------|--------|------|----------|
| 1 | `permit_recruit(ob)` | — | 基础门控 |
| 2 | `family_name == "少林派"` | 必须已是少林派 | 「与本派素无来往」 |
| 3 | `class == "bonze"` | 必须出家 | 「俗家弟子，不能在寺内学艺」 |
| 4 | `ob_fam["generation"] == 36` | 必须是玄字辈 | 「贫僧哪里敢当」 |
| 5 | `query_int() >= 35` | 悟性≥35 | 「悟性仍有不足」 |
| 6 | `query("WPK") <= 3` | 杀戮值≤3 | 「杀戮心太重」 |
| 7 | `buddhism >= 180` | 佛法≥180 | 「禅宗心法领悟得不够」 |
| 8 | `dodge >= 180` | 轻功≥180 | 「基本轻功火候尚有欠缺」 |
| 9 | `force >= 180` | 内功≥180 | 「基本内功火候尚有欠缺」 |
| 10 | `parry >= 180` | 招架≥180 | 「基本招架火候尚有欠缺」 |
| 11 | `combat_exp >= 1,000,000` | 经验≥100万 | 「实战经验还颇有欠缺」 |

全部通过后，改名为 `渡` + name[1..1]（渡字辈），执行 `recruit`。

## 7. 与 UCL 的对比与建议

| 项目 | LPC 实现 | UCL 当前状态 | 建议 |
|------|----------|-------------|------|
| 门派标识 | `create_family("少林派", gen, title)` | sects.ex 中有 `shaolin` 原型 | ✅ 已存在 |
| 俗家弟子入门 | 清无/清为/清法直接收徒 | 无配置 | ⚠️ 需补充 |
| 剃度出家 | 清法 `ask_for_join` + `kneel` 受戒 | 无机制 | ⚠️ UCL 暂不支持剃度仪式 |
| 出家门控 | `class == "bonze"` 才能入寺 | 无配置 | ⚠️ 需补充 |
| 推荐信 + 斗武 | `damo ling` + 斗武胜利（NPC气血≤50%） | 无机制 | ⚠️ UCL 暂不支持 |
| 辈分制 | 玄/澄/慧/道/清/渡，改名 | 无配置 | ⚠️ UCL 暂不支持辈分 |
| 达摩祖师门槛 | int>=35, buddhism>=180, exp>=1000000 等 | 无配置 | ⚠️ 需简化或以备注体现 |
| 可教武功 (`teach_skills`) | 50+ 项 (set_skill) | 无配置 | ⚠️ 需回填 |
| 不可教 (`no_teach`) | shaolin-jiuyang | 无配置 | ⚠️ 可补充 |
| 绝招 (`inquiries`) | 达摩剑四绝 + PFM 六绝 | 无配置 | ⚠️ 可补充 |
| 师父 NPC | 40+ 个固定 NPC | 无 room_characters 配置 | ⚠️ 需补充位置 |

**结论**：少林派在 LPC 中有完整的入门、剃度、辈分晋升、达摩高门槛收徒机制，但机制复杂（剃度仪式、推荐信、斗武、辈分改名），UCL 当前尚未建模。若要将少林派加入第 2 节详细条目，需先在 UCL 层支持剃度与辈分机制，或先按「简化版」记录门槛，剃度和推荐信部分以文本备注形式体现。

## 8. 新手建议路径

1. **前往少林寺前广场**，找到清无、清为、清法三僧
2. **男性玩家**：直接拜任一僧为师，成为「俗家弟子」，学入门功夫（shaolin-xinfa、cibei-dao 等）
3. **剃度出家**：向清法比丘询问「剃度」，执行 `kneel` 受戒，成为 `class = "bonze"` 的出家人，法名改为「虚/空/明/净」开头
4. **入寺**：通过山门，进入寺内练武场
5. **拜入长老**：持达摩令，与长老斗武胜利，获得推荐信，拜入慧/道/澄等字辈长老为师
6. **晋升辈分**：通过斗武与推荐信，逐步晋升为澄、慧、道、玄、渡字辈
7. **达摩祖师**：武功、悟性、经验均达标后，可挑战达摩祖师，成为渡字辈关门弟子
