## 1. 审计结论

凌霄城（雪山剑派）在早期 #619 批次落齐了 12 个 NPC 的 `skills` / `teach` / 绝招 `inquiries`，
但**收徒门控与 NPC 战斗行为显著欠移植**，且其中一条是**方向性错误**：

1. **收徒门控方向性错误（最严重）**：`lingxiao.h::permit_recruit` 无条件 `return 0`：

   ```c
   int permit_recruit(object ob)
   {
           command("say 对不起，我雪山剑派不对外收徒。");
           return 0;
           /* 旧 detach/betrayer/他派三段判定全部被注释掉 */
   }
   ```

   而 UCL 里 12 个 `apprentice` 块**全部** `permit_recruit = true`，白万剑 / 白自在 / 史婆婆
   甚至把 LPC 不可达的 `min_shen`/`min_exp`/`min_skills`/`reject_master_name` 都抄了下来。
   12 个 NPC 里只有石清**没有** `attempt_apprentice`，UCL 却给他编了一个会收徒的块
   （`accept_msg = "好吧，那我便收你为徒..."`）——完全是编造。
   → 12/12 改为 `deny_all = true` + 逐字 `deny_msg = "对不起，我雪山剑派不对外收徒。"`。
   `apprentice.c` 无默认 `attempt_apprentice`，`cmds/skill/apprentice.c` 直接
   `ob->attempt_apprentice(me)`，故石清连拜师命令都不会有回应。

2. **战斗闲聊 12/12 全缺**：每个 NPC 都有 `chat_chance_combat = 120` +
   `chat_msg_combat`（4–6 条 `perform_action`/`exert_function`）。白万剑/白自在/史婆婆/花万紫
   各 6 条，王万仞/闻万夫/耿万钟/柯万钧/陆万通/呼延万善/张万风 各 5 条，石清 `chance = 100`
   3 条。王万仞另有非战斗闲聊（UCL 已有）。

3. **白自在「三连环」问询是占位**：`baizizai.c` 的 `inquiry` 里
   `"三连环" : (: ask_skill2 :)` 与 `"神倒鬼跌三连环" : (: ask_skill2 :)` **同一函数**，
   UCL 写成 `{ key = "三连环" value = " inquire about skill2 (unimplemented)" }`。

4. **陆万通缺 coagents + guarder**：`luwantong.c` 同时 `inherit F_MASTER` 与 `F_GUARDER`，
   `set("coagents", ...)` 指 白万剑，`set("guarder", ...)` 两句拒绝台词。
   `d/lingxiao/dadian.c::valid_leave` 对 east/west/north 三向调 `lu->permit_pass(me, dir)`，
   UCL 里 dadian 房间**没有** `behavior_config`，守卫恒不拦（fail-open）。

5. **石清两条独有机制**：
   - `recognize_apprentice(ob, skill)`：`master_name != "白自在"` → 「素无渊源」；
     `shen < 10000`；`skill` 必须是 `shangqing-jian` 或 `sword`；`sword > 179` 拒。
     当前 `SectMaster.recognize_apprentice_reply/3` 只认 `no_teach_unlock` 的
     `restricted_skill` + mark 形状，**覆盖不到**（GAP #1025）。
   - `ask_jian`（「墨剑」）：`is_bad()` → 两句按门派分支；非同门；`master_id != "bai zizai"`；
     `shen < 30000`；`shangqing-jian < 150`；然后走 **墨剑物品 owner 状态机**
     （`find_object(MOJIAN)` → 逐层 `environment` 找持有者 → 本人/他派/本派三分支 →
     `command("give mo jian to ...")`）。`give_item` 现无 `is_bad` 分支、无 owner 状态机
     （GAP #1024/#1015 同族）。

6. **闻万夫 `kill_ob` 群体助战**：被 kill 时 `set_temp("my_killer")` → `::kill_ob(ob)` →
   找同房间 `lingxiao dizi` / `2` / `3` 三个弟子，各自 `kill_ob(ob)`，并对第一个未被缠住的
   弟子 `message_vision("闻万夫大怒，喝道：居然欺到我们凌宵城头上来了，大家并肩子上！")`。
   ex 端 NPC 被攻击时只通知自己登记的 `coagents`，闻万夫没有 `coagents` → 无人助战
   （GAP #1027）。

7. **白万剑 `unconcious()` 死亡覆写**：`void unconcious() { die(); }`。LPC 下白万剑气/精归零
   走 `damage.c::unconcious`（`run_override("unconcious")` 命中 → 直接返回），
   `die()` 里 NPC 分支 `destruct(me)` 真销毁，尸体落地。
   ex 端 `Feature.Damage.run_override/2` 恒 `false`，`combat_event` 在 `vitals.qi <= 0` 时
   直接 `die/3`，NPC 走「原地装死 + 60s 复活」——语义与 LPC 相反（GAP #1026）。

8. **门派/文本保真旧债（沿用红花会口径）**：`msg_one`/`learned` 里的字面 `\n`、
   `message_vision` 的颜色与 `$n/$N` 广播格式，与 LPC 原文仍有差异（GAP #1029）。
