## 1. 审计结论

少林派在早期 #619 批次落齐了大部分师父的 `teach` / 收徒 `apprentice` / 绝招 `inquiries`，
但存在**系统性机制缺口 + 一批战斗行为/对话/守卫丢失**，另有若干 `unimplemented` 占位。

### 1.1 系统性 GAP：NPC 顶层 `skills = [...]` 列表从未被解析（最严重，全门派波及）

`loader.parse_character`（563–643）与 `npc_stats/1`（1950–1961）**从不读 `character_data[:skills]`**，
只读 `combat.skills`（map 形式）与 `combat.map_skill`。而 423 个 NPC 块在顶层写了
`skills = [{ skill=..., level=... }]` 列表（如 `shaolin_dao_chen` 40841–40857），
这些 `skills` 全部被丢弃 → `stats.skills` 为空 `%{}` → `SectMaster.teachable?/2`
（`skill_level > 0`）恒 false → **NPC 无法授艺、战斗技能等级全 0**。
→ 系统级 GAP，**不能在本门派批次内修**，单独登记 Task。

`maybe_combat_chat` + `publish_combat_say`），**纯数据回填**。当前 8 个 NPC 全无。

### 1.5 收徒拒绝（`attempt_apprentice` 纯拒徒台词）丢失（3 个 NPC）

LPC `attempt_apprentice` 为**纯拒绝**（无 permit 链），需 `apprentice.deny_all = true` + 逐字 `deny_msg`：

| NPC | LPC `attempt_apprentice` 台词 | UCL `deny_all` + `deny_msg` |
| --- | --- | --- |
| 觉远 | 「贫僧乃戴罪之身，岂能收徒。」 | 需补 `apprentice` 块 |
| 空见 | `message_vision("$N双手合十对$n道：善哉善哉，老衲早已不收徒了。\n")` | 需补 `apprentice` 块 |
| 无名老僧 | 同门「我早就不收徒弟了…就传你…」／异门「我只是少林的一名扫地僧，哪里懂什么武功。」 | 需补 `apprentice` 块 |

空见当前 `apprentice` 块**缺失**（只有 `teach`）→ 按惯例无块 = 不收徒，但需显式 `deny_all` 补台词
（同 LPC 只有 `teach` 的石清先例）。
