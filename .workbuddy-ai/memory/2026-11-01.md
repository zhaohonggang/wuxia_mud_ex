## 关键边界修正（重新分类器证实）
- **con/int/str/dex/per 在 Stats 结构体内**：`me->query("con")` 取派生根骨，应映射 `Stats.query_con(stats)`（arity-1 即可，无需 arity-2）。
- **仅 gender / max_neili(vitals) / 装备 weapon(secondary) / family / personality / marks / reborn 需要 arity-2**（`valid_learn(stats, character)`，角色取 `meta.env`/`meta.vitals`/`Skill.wielding?`/`wielded_skill_type`）。
- **`::valid_learn(me)`** → arity-2 末尾回落 `valid_learn(stats)`（继承 query_skill 门）；**`return 1`** → 全部门槛显式列出，无回落。
- **LPC 注释代码需忽略**（zixia 的 gender 门、`yijinjing` 的 freezing-force 均为 `//` 注释）——旧分类器未去注释，导致虚高计数。
- **副作用/动态门**：`me->set`/`write`、`query_condition`、qiankun 的 `int<29+layer` 动态门 不建模（valid_learn 是谓词）。
