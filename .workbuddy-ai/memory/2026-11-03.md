### 经验（防呆）
- **配置里写 Elixir 模块名做动态分发时，字符串→atom 必须带 `Elixir.` 前缀**，否则生成的是
  另一个无绑定的 atom，所有 code-server 查找静默失败。
- 容器 `_build/test` 是 named volume（`app_build`），宿主机 `rm -rf _build` 清不掉；要清须
  `docker compose ... run --rm app sh -c "rm -rf /app/_build/test"`。
