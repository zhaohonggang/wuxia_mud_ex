# Workspace Memory — wuxia_mud_ex (Elixir/Phoenix LPC MUD port)

## Conventions (iron rules)
- **No `git commit`** unless explicitly asked. P6 housekeeping (commit) pending user approval.
- **No local Erlang** — Docker is the authoritative verify path:
  `docker exec -e MIX_ENV=test -e TEST_DATABASE_URL=postgresql://postgres:postgres@db:5432/ex_venture_test wuxia_mud_dev-app-1 sh -c "cd /app && mix test <path>"`
  Plain `mix test` fails (localhost:15432 unresolved in-container). Containers: `wuxia_mud_dev-app-1`, `wuxia_mud_dev-db-1`.
- **UCL (Elias parser)**: block members newline-separated, NO commas; bare keys (incl. Chinese); inline objects multi-line `key = { subkey = value }`; `newline=""` to avoid CRLF. **String escapes**: inside `"..."` only `\"`/`\'` and `\`+word (`\n`/`\t`) are legal; **`\\` is a syntax error**; **real newline in string is a syntax error**; Elias does NOT unescape. Encode order: escape backslash/quote FIRST, then newline→`\n`. `validate_ucl.py` has `EliasStrings` check. **Arrays**: comma-separated, NO trailing comma. Illegal in `"..."`: `[` `]` `;`.
- **Backfill discipline (G1–G8)**: dry-run → backup `tmp/backup-<name>-<YYYYMMDD-HHMMSS>/<zone>.ucl` → apply (`newline=""`) → `validate_ucl.py` green → idempotent re-run = 0 pending.

## Test gotchas
- **`:global` name race**: never stop/start a process under same `:global` name repeatedly (full-suite `already started`). Use `setup_all` register once + per-test `reset/1` (clear exits/state + cancel `exit_timer:*` timers).
- **Duplicate test helpers**: Elixir matches only FIRST clause of same-name/same-arity def — silent wrong config. Never redefine `defp cfg_x/0` twice.
- **Verified counts**: full `test/kantele/world/` = **1297 tests / 0 failures** (post P5-4an, includes 35 push + 22 knock_pull + 34 trigger + 46 move_stone tests); full `mix test` = 4209/0 (post P5-4af). `Helpers.broadcast_vision/4` normalizes `$N`→`{npc}`; assert `{npc}` not `$N`. `Room.exits` is a LIST of `%Kalevala.World.Exit{}`. `Conn.publish_message` preserves `conn.private.update_character` (broadcast does NOT clobber char mutations). 复用同一 conn 多次调用时 `conn.private.channel_changes` **累积**，断言 `published` 要取 `List.last` 或逐次新建 conn。字母序注意 `"jingzhou:houyuan"` < `"jinshe:shanbi"`（第 4 字符 g<s）；`"kaifeng:*"` < `"lingxiao:*"`、`"shaolin:beilin2"` < `"shaolin:guangchang1"`、`"tiezhang:*"` < `"wanjiegu:*"`、`"emei:hcadadian"` < `"emei:hcawest"`——手插位置易错，**直接从注册表输出重排整块字面量**最稳。
