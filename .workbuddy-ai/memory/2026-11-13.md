### 7. 修复 websocket Jason.Encoder 协议崩溃（完成）

- 错误：`Jason.Encoder protocol must always be explicitly implemented` for `#Reference<...>` at `Kalevala.Websocket.Handler.websocket_info/2` (vendor/kalevala/lib/kalevala/websocket/handler.ex:71)
- 根因：`Kalevala.Event` 结构体未实现 `Jason.Encoder`，其 `data` 字段可包含 `make_ref()` 生成的 Elixir `Reference` 值（见 `lib/kantele/scheduler.ex`、`lib/kantele/world/room.ex`）。websocket 处理器 `Jason.encode!` 事件列表时遇到 `Reference` 崩溃。
- 修复：在 `vendor/kalevala/lib/kalevala/event.ex` 为 `Kalevala.Event` 实现 `Jason.Encoder`：
  - `from_pid`（PID）转为字符串（`:erlang.pid_to_list/1`）
  - `data` 字段先通过 `encodable?/1` 检查是否可 JSON 编码，不可则替换为 `nil`
  - `metadata`、`topic`、`acting_character` 正常编码
- `mix compile MIX_ENV=test` 通过，0 警告 0 错误

### 8. 修复 websocket Jason.Encoder 协议崩溃：Kantele.Character.Combat（完成）

- 错误：`Jason.Encoder protocol must always be explicitly implemented` for `%Kantele.Character.Combat{...}` at `Kalevala.Websocket.Handler.websocket_info/2` (vendor/kalevala/lib/kalevala/websocket/handler.ex:71)
- 根因：`Kantele.Character.Combat` 结构体未实现 `Jason.Encoder`，其字段包含 `MapSet`（`attacked_by`）和可能含 `:pid` 的 `enemies` 列表。websocket 处理器 `Jason.encode!` 事件列表时遇到这些不可编码值崩溃，导致玩家进入战斗后一连断线。
- 修复：
  - `Kantele.Character.Combat.Buff`：加 `@derive Jason.Encoder`
  - `Kantele.Character.Combat`：实现 `defimpl Jason.Encoder`：
    - `attacked_by`（MapSet）→ 排序后的列表
    - `enemies` 中的 `:pid`（PID）→ 字符串（`:erlang.pid_to_list/1`）
    - `buffs` 使用 `Buff` 的 `@derive Jason.Encoder`
    - `equipped`/`temp`/`busy`/`jiali`/`dead`/`helping` 直接编码
  - 顺便清理了重复的 `interrupt/1` 定义和恢复了被误删的 `apply_damage/2`
- `mix compile MIX_ENV=test` 通过，exit code 0
