### 解析器踩的坑（都成了脚本注释）

3. **裸 `present(id)` 单参**：求值器 `apply_func("present", [id, scope])` 双参解构 → 单参 MatchError！按 LPC 语义补 `,this_object()`（`this_object()` 求值器回 room；`scope_is_room?` → find_in_room）。**逗号后不能有空格**（elias 拒 `, x`）。

5. **嵌套单语句 if + 块**（`if(a) if(b){...}`）：read_statement 的 `;` 直扫会把块收尾 `}` 切掉 → 必须先找 `;` 前的 `{` 按块配对；handle_if 的 `startswith("if")` 必须**先于** is_block 判断。
6. **放行守卫语义**：`if(c) return 1;` 的取反累积作用于块内后续语句；简单比较才可取反，复杂 → 本块后续候选作废（缺守卫 = veto 比 LPC 更激进 = 锁死玩家，宁缺毋滥）。else 分支同样要 NOT(cond) 守卫，取不了反就不递归。
7. **去重方向感知**：转换器把 `dir=='a'||dir=='b'` 截成单方向（chengdu/wuguan 只留 up）→ 同 cond+msg 不同方向 = 真缺口，必须放行补全方向。
